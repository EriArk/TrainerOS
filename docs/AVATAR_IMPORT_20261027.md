## Воспроизведение и проверки

`tools/avatar/import_approved.py APPROVED_ROOT LEGACY_V3_PACK OUTPUT` собирает
пакет из сохранённых авторских GLB. Входные v3 текстуры/маски восстанавливаются
из `ebfdd07c:assets/avatar/packs/trainer-avatar-1`. SHA-256 входов и выходов
находятся в manifest. Существующие варианты almond получают масштабированный
патч относительно исправленного тела, без возврата старой головы/шорт.

Проверка настоящим Qt выявила и устранила три ошибки упаковки: неверное
соответствие цветовой текстуры после дедупликации, полностью нулевой sparse UV
без bufferView и отсутствие белого COLOR_0 у текстурной части составного тела.
Для каждого случая добавлена регрессионная проверка. Sparse используется только
для корректирующих дельт; основные атрибуты хранятся явно.

- Нативная ARM64 сборка с Qt Quick3D/AssetUtils прошла.
- AvatarTests: **6 passed, 0 failed, 0 skipped**; все 14 вариантов, четыре
  причёски, разные палитры, сохранение/отмена, recipe и отдельность черновика.
- PlatformHostTests: **14 passed, 0 failed, 1 skipped**. Пропущен внешний
  Godot-потребитель: в этом окружении нет Godot. Историческая приёмка не выдаётся
  за новую проверку обновлённого пакета.
- UI smoke: результат фиксируется отдельно от визуальной приёмки. Offscreen Qt
  успешно проверяет загрузку и переходы, но не рисует Quick3D в этом окружении.
  Для материалов использованы реальные окна Qt на Windows: новый портрет,
  светлая/тёмная кожа, цветные волосы/радужки и освобождение рендера после снимка.
- Backend: **23 passed** в изолированном PostgreSQL на сервере; API/worker
  `traineros-backend:avatar4-20261027` запущены, `/health/ready` вернул 200.
  Миграции БД не было, Lobby bot не затронут.

Локальные журналы и диагностические рендеры: `build/avatar27`. Сборка ARM64
и её контейнерное хранилище находятся на microSD Odin. Сборка полного Windows
shell остановлена после зависшего линкера; она не заявлена как прошедшая.

## Границы

Физическая приёмка кнопок владельцем, новый игровой прогон в Godot и проверка
между разными сетями не выполнялись в этом импорте. Моргание, движение взгляда
и физика ткани не добавлены. Художественное одобрение сохраняется, но не заменяет
эти отдельные проверки. Происхождение и условия ассетов остаются в
[уведомлениях](../assets/avatar/README.md).
