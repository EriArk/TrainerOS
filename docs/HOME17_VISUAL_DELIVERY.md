# Home — визуальная коррекция, 16 октября 2026

Продолжение [HOME-16](HOME16_FRAMEWORK_EVIDENCE.md), после отклонения владельцем
его PC-снимков. Работа идёт по одному экрану: Home → установка на Odin → просмотр
владельцем; Games ждёт. Flip отложен по прямому ответу владельца.

## Принятые детали

- Общая красочная иллюстрированная сцена сохраняется и при первом запуске.
  Нет контактов/наград — оформленные приглашения начать, а не пустые белые панели.
  Декоративные пустые места не являются заблокированными или полученными RA.
- Кнопка A снова круглая, объёмная, с прежним материальным оформлением. Её
  крепление стало меньше; shell сохраняет единственную цель Play/Return/Choose.
- Скриншот полупрозрачно покрывает всю игровую карточку. Текст, прогресс и
  адаптерная презентация поверх него. Отдельный preview вместо фона отклонён.
- RA показываются значками в круглых оправах, без прямоугольных текстовых плиток.
  Подпись выбранной награды и Offline сохраняются; переход использует прежний ID.
- `BadgeName` берётся из существующего ответа RA и сохраняется в прежнем
  account-scoped metadata-кэше. Отсутствующее/невалидное имя не отменяет подтверждённую
  разблокировку и не превращается в произвольный URL. Старый кэш совместим.
  Картинки лениво загружает QML с ограниченным sourceSize и memory cache;
  отдельного постоянного кэша изображений на диске пока нет.

Контракт artwork сверён с официальным rcheevos:
[patch response](https://github.com/RetroAchievements/rcheevos/blob/master/src/rapi/rc_api_runtime.c),
[image URL](https://github.com/RetroAchievements/rcheevos/blob/master/src/rapi/rc_api_common.c).
