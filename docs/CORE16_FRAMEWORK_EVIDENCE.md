Область: [актуальный контракт](UX_CONTRACT_20261016_RU.md),

## Что изменено в исходниках

- Пять разделов: Home / Games / GameHub / Social / Apps. Сохранённые маршруты
  переведены на semantic IDs и schema 3; старые numeric/Pokédex/Companions/Trainer/
  Hall/Social Lobby маршруты имеют явную миграцию.
- GameHub содержит Overview, RetroAchievements, optional именованный Adapter
  и Lobby. У generic игры нет пустой Adapter-вкладки. Overview имеет вложенные
  Timeline и Screens: история берётся из существующего репозитория, Screens пока
  показывает только имеющийся подтверждённый Exit-кадр, не готовую новую галерею.
- Контракт Experience v2 заменяет два обязательных слота одной optional surface
  с именованными экранами. Pokémon перенесён в девять экранов левого меню;
  RA остаётся общей службой. Выбор и непрозрачное состояние сохраняются отдельно
  для профиля, игры и модуля. Идентичность, generation guards и защита сейвов сохранены.
- Social имеет три L2/R2 peer: Messages / Communities / Discover. Lobby смонтирован
  в GameHub и доступен по существующим входам. Глубокая переработка Social в #217–223
  ещё не выполнена: старые внутренние проекции/списки провайдера пока сохраняются.
- Apps имеет Apps / Crates / Browser / Files. Каталог Apps остаётся рабочим;
  три будущих поверхности явно сообщают об отсутствии функции в этой сборке.
  Это маршруты, не встроенный браузер, файловые операции или готовый магазин.
- X открывает общий Quick Apps, Y — существующий список недавних игр.
  Клавиатура и защищённые операции сохраняют приоритет. Поиск/фильтр Games
  доступны на экране и через контекст, скрытые Apps — через Select; меню приложения
  вынесено на общий слой. Предпросмотр звонка не отвечает на него автоматически.
- Chassis использует реальные логические размеры окна вместо масштабирования
  фиксированного 960×540. Док растёт вверх от правого нижнего угла; верхние кнопки
  остаются на своих местах. Старые экраны ещё требуют дальнейшей адаптации.
