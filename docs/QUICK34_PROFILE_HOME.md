# QUICK-34 — профиль на корпусе и объёмный Home

16 октября 2026. Последние уточнения владельца; продолжение QUICK-32.

## Принятый результат и порядок

1. Значок X на ушке на 4 единицы правее; нижние подсказки X/Y убрать,
   сами действия и ушки сохранить, остальные подсказки оставить.
2. Вместо Trainer OS — круглый аватар и имя текущего Fluxer-пользователя.
   По касанию карточка над текущим экраном: профиль, статус и ключ редактирования.
   Повторно использовать CommunicationSettings и FluxerSession; не смешивать
   сетевую личность с локальным Trainer. Без входа — явный вход, без ложного Online.
3. Редактор: отображаемое имя, аватар из Pictures, описание. Статус доступности
   и текстовый статус через штатный Fluxer settings API; подтверждённое сервером
   состояние, ошибки и защита от ответов прошлого аккаунта/старого запроса.
4. Home: заголовок Activity удалён, друзья и уведомления подняты на 32 единицы в освободившееся место. Чуть меньше карточка, объёмная кромка, мягкая тень. Пять новых фоновых
   иллюстраций под палитры корпуса, только внутри карточки. Адаптер сохраняет
   свою компоновку; фон скриншотом не возвращается.
5. Проверки маршрута/клавиатуры/Back, ошибок провайдера, UI/тем; сборка и
   доставка на доступные Odin/Flip, просмотр реальных кадров, commit/push.

## Источники

- Текущие уточнения владельца дополняют #130/#227; текущий игровой маршрут,
  игры, сохранения и вызовы не должны меняться при открытии профиля.
- [Fluxer user settings](https://docs.fluxer.app/http-api/users/settings/):
  GET/PATCH `/v1/users/@me/settings`, статусы online/idle/dnd/invisible,
  custom_status; обновления распространяет провайдер через Gateway.
- Редактор имени/изображения/описания использует существующий `/v1/users/@me`.
