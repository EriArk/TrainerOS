# Проверенные игры мультиплеера

Общий журнал конкретных игровых проверок TrainerOS. Начальный набор — PSP;
остальные платформы добавляем по мере проверок. Состояние самой функции и её
зависимости остаются в [карте готовности](FEATURE_READINESS.md#r037).

**Обозначения:** ☑ — указанный сценарий пройден; ☐ — не подтверждён;
⚠ — есть воспроизведённая проблема. Галочка относится к описанному сценарию,
изданию и сборке, а не ко всем режимам игры. Старые результаты не становятся
новой проверкой после обновления эмулятора. При новой проверке добавляем строку
для другого пути/сборки и сохраняем прежнюю проблему до подтверждённого исправления.
