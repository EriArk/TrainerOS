# English collection curation — 2026-09-24

The owner requests one English copy of each game, including the missing reference
checklist. Distinct editions such as Red/Blue, remakes, sequels and independent
ROM hacks remain distinct. Revisions, language dumps and Virtual Console wrappers
do not create extra cards. Native console games, including Snap, Pokken, Smash,
Mystery Dungeon, Ranger, Conquest, Pinball, Puzzle and Rumble remain eligible.

Exclude GO and other mobile clients, companion/storage utilities, educational
PC/Pico discs and special-input utilities. Examples: [GO](https://support.pokemon.com/hc/en-us/articles/360001215853-About-Pok%C3%A9mon-GO),
[Pokken DX](https://www.pokemon.com/us/pokemon-video-games/pokken-tournament-dx/)
and [New Snap](https://newpokemonsnap.pokemon.com/en-us/) have different roles;
the latter two are intentionally retained. This is the owner's collection policy,
not a claim that every retained title already has a working emulator route.

The bundled data retains excluded identifiers with reasons for matching existing
records and preventing reimport under a new name. Only 92 of its 216 references
are visible/linkable. English fan translations of Japan-only games can appear
as actual installed games, without an untranslated grey card. Existing IDs,
saves and history are not merged or deleted by the presentation projection.
Empty Worlds disappear. Non-Pokemon Multiverse content is unaffected.

Language decisions use explicit dump tags, variant metadata and curated reference
identity. En-containing multilingual releases remain eligible; Japan and other
non-English language tags, including short codes, are excluded. Unknown filenames
are not proof of language: retain useful untagged hacks unless the reviewed device
cleanup classifies them as ambiguous/service material. No exhaustive in-game
language certification is claimed for hundreds of community hacks.

Stable duplicate projection prefers available/configured records; ties use the
stable ID. The one-time device cleanup additionally prefers explicit English
translations, used/Home copies, ordinary retail over LodgeNet, and later/completed
releases where the metadata is clear. Alternate titles for Card GB2 and translated
Green share a duplicate identity. Distinct hack titles never merge into their base.

The owner separately authorized permanent removal of rejected device ROMs,
including ambiguous builds. A private reviewed manifest records exact paths,
reasons, sizes and file identity. The server originals are untouched. Before unlink,
verify the library root, no symlinks/shared retained paths, matching database
revisions and an idle stopped shell. Preserve a database/XML/program backup;
ROMs are not copied into trash. Remove matching gamelist entries, retain tombstones
for history, and preserve save files. The operation is maintenance, not an
automatic destructive side effect of future scans.
