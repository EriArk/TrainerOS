# Выражения лица — 28 октября 2026

[Визуальный обзор](evidence/avatar-face-20261028/review.html) ·
[API для разработчика](../sdk/AVATAR_EXPRESSIONS.md)

Общий runtime-пакет revision 5 добавляет восемь форм рта, девять выражений
(включая нейтральное) и четыре разовые реакции. Рот управляется отдельно,
переходы плавные, сила регулируется. Все четырнадцать выбранных пар глаз
остаются совместимыми. Это новая работа для визуального просмотра владельцем;
она не меняет статус ранее утверждённых исходников.

## Владельцы и жизненный цикл

S01/TrainerController сохраняет постоянную внешность. S04/AvatarAssets собирает
GLB из общего пакета. S14 SDK загружает проверенный файл; игра управляет
временным выражением конкретного экземпляра. Сохранённый профиль, рецепт
соперника и сетевые полномочия не расширены. Основное выражение переживает
короткую реакцию, последняя реакция заменяет предыдущую. Отзыв профиля удаляет
модель и состояние лица. Замена внешности начинает с нейтрального выражения.

Старый нарисованный рот убран через recolorable vertex-color поверхность,
новые контур/зубы/язык находятся на отдельном skinned mesh `Face_Mouth`.
Закрытые позы скрывают внутренние части геометрически; открытая O-форма без
зубов. Сетка повторяет кривизну лица и закреплена за head joint.

Для старых `round`/`almond` используются исходная поверхность тела и отдельные
участки с рисунком глаз/бровей, соединённые по неподвижной границе. Вырезанные
треугольники не дублируются под ними. Для двенадцати модульных пар сохраняется
утверждённое подготовленное лицо. Необязательная таблица `eyeBodyMeshes` в
manifest выбирает подходящую поверхность; старые пакеты используют прежнее
правило. Поэтому revision 5 устанавливается вместе с обновлённым resolver.

Имена morph targets и пресеты записаны в GLB. 54 кости, 46 body correctives и
восемь исходных анимаций сохранены. Новые лицевые targets отдельные, анимации
тела их не перезаписывают. Qt-карточка использует нейтральный preview без morphs.
Все body primitives имеют COLOR_0: Qt/Assimp не превращает оставшиеся поверхности
в чёрные при добавлении цветного skin patch.

## Воспроизведение

Исходник: [`tools/avatar/build_expressions.py`](../tools/avatar/build_expressions.py).
Python 3.12, numpy, scipy и Pillow; генератор принимает отдельный **revision 4**
и записывает revision 5 в другой каталог. Revision 4 воспроизводится из commit
`6e3ae0ca`, каталога `assets/avatar/packs/trainer-avatar-1`:

```sh
git archive --format=zip --output=revision4.zip 6e3ae0ca assets/avatar/packs/trainer-avatar-1
# Распаковать архив в revision4/, затем:
python tools/avatar/build_expressions.py revision4/assets/avatar/packs/trainer-avatar-1 output/face-pack
```

Результат: `assets/avatar/packs/trainer-avatar-1/template.glb`, 42 637 868 байт,
SHA256 `650e95b8a9b162b4eebb85bdc636640f0c7657e5a6845aa4b118f6dc388ceca3`.
Бинарные offset старых almond patches сохранены. Изменены только runtime GLB
и manifest; все утверждённые GLB/Blender-файлы в `assets/avatar/approved`
сохранены. Рот и morphs созданы процедурно; чужие игровые модели/текстуры не
импортировались. Референсы чиби-выражений просматривались у
[MapleStory 2](https://www.gamemeca.com/view.php?gid=857047) и
[Fantasy Life i](https://www.rpgsite.net/news/18182-fantasy-life-i-version-1-5-0-update-patch-notes-release-date-photo-mode).
Права на исходное тело/волосы остаются в [реестре ассетов](../assets/avatar/README.md).

### Портативки и исправление Compatibility

На Odin 2 / Flip 2 запущен отдельный ARM64 SDK-пример с полным GLB revision 5:
десять кадров на каждом (девять выражений и wave в три четверти), переходы,
независимые экземпляры, ручной рот и отзыв. Исходная GPU-реализация Compatibility
вытягивала геометрию при сужении глаз; логические проверки сами по себе этого не
обнаружили. После просмотра кадров исправлен общий presenter: для Compatibility
он вычисляет только маленькие лицевые morphs на CPU, сохраняя UV/материалы/skin.
Тело и скелет остаются на GPU. Mobile сохраняет GPU morphs. CPU-обновления нужны
во время переходов, а не непрерывно после установившегося выражения.

Повторные кадры после исправления просмотрены:
[Odin, смех](evidence/avatar-face-20261028/odin-laughing.png),
[Flip, усталость](evidence/avatar-face-20261028/flip-tired.png).
Профили и процесс оболочки проверены до/после; они не изменились. Пример,
модель и кэши размещены на SD. Odin оставлен с громкостью 0.

**Поставка:** общий revision 5 и новый resolver находятся в исходниках;
на портативках проверена отдельная SDK-сцена, системный pack revision 4 и
бинарник оболочки не заменялись. Их совместное обновление остаётся отдельной
поставкой. Это не проверка автоматических игровых реакций Pocket Golf.

## Остаётся отдельно

Слоговые рты и lip-sync отложены по запросу владельца. Полное моргание и взгляд
также не добавлены. Сетевые эмоции игра выводит из своих событий либо передаёт
через существующий проверяемый канал — новый транспорт здесь не создаётся.
Pocket Golf и другие установленные игры пока не привязывают игровые события к
этим реакциям автоматически. Для этого им нужен обновлённый presenter и вызовы
API в соответствующих местах логики.
