## Исправление общего механизма

`MultiplayerRoute.h` выбирает стандартный сетевой adapter/core на копии
регистрации. Одни и те же параметры используются при построении профиля,
подготовке и запуске. Обычная привязка игры в библиотеке и личные сохранения
не переписываются. Поэтому PS1, зарегистрированная для DuckStation на одном
устройстве, теперь находится для Lobby с PCSX-ReARMed, как на другом.

Общий допуск больше не выбрасывает `runtime` и `core` перед сравнением.
Совпадения названия эмулятора/протокола недостаточно: проверяются объявленные
сборка, настройки, контент и firmware. Подмена локального файла после Ready
также отклоняется. PS2 LAN helper сохраняет эту проверку при запуске.
Известная установленная игра с несовместимым профилем получает причину
`runtime-mismatch`, а не предложение повторного импорта ROM.

Это строгий допуск текущего ARM64-набора. Совместимость разных архитектур
потребует отдельного проверенного соответствия артефактов; произвольные
разные хеши не считаются совместимыми. Native games Crates используют свой
протокол, а не равенство x86_64/ARM64 исполняемых файлов.

## Влияние BIOS

Для rollback обе машины должны воспроизводить одно состояние: загружаемый
BIOS может менять исполнение и поэтому входит в проверку соответствующего
профиля. Это не требование сравнивать всю папку BIOS для любого мультиплеера.
[Механизм RetroArch](https://github.com/libretro/docs/blob/master/docs/development/retroarch/netplay.md).

- PS1 выбирает один BIOS и копирует его в приватный каталог сессии. Дополнительные
  обычные BIOS не влияют на этот выбор.
- FBNeo может искать отсутствующие части ROM/BIOS в нескольких архивах.
  Совпадение общих членов ZIP при разном наборе дополнительных BIOS само по себе
  не доказывает рассинхронизацию. Сейчас проверка архивов консервативна;
  содержимое реально используемых членов пока отдельно не канонизируется.
  [Поиск и загрузка FBNeo](https://github.com/libretro/FBNeo/blob/master/src/burner/libretro/libretro.cpp),
  [выбор Neo Geo BIOS](https://github.com/libretro/FBNeo/blob/master/src/burner/libretro/retro_common.cpp).
- PSP использует HLE; внешний BIOS для этой проверки не нужен.
- Сетевой melonDS использует подготовленные FreeBIOS/firmware своего профиля.
- Native LAN PS2 не объявляет весь личный BIOS/NVRAM обязательным общим
  состоянием; карты памяти и INI остаются индивидуальными.
- Remote Play исполняет игру только у ведущего: гостю не нужны её ROM или BIOS.
