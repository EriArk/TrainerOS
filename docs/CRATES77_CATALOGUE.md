# CRATES-77 — обновляемый каталог и оставшиеся примеры

## Первые авторские приложения — 21 октября 2026

- В публичном подписанном каталоге опубликованы Session Timer 0.1.0 и Pocket
  Artillery 0.1.0, Linux x86_64 / Experimental / untested. Ревизии 3 и 4 добавили
  проекты в Workshop/What's New и тематические ящики с настоящими скриншотами.
  Все прежние пять проектов и записи пакетов сохранены без изменения.
- Пакеты, соответствующие исходники, записи и SHA256SUMS доступны в
  [Session Timer release](https://github.com/EriArk/crates/releases/tag/session-timer-v0.1.0)
  и [Pocket Artillery release](https://github.com/EriArk/crates/releases/tag/pocket-artillery-v0.1.0).
  Сервер по-прежнему хранит только подписанные метаданные/маленькие изображения.
- Проверен реальный HTTPS delta 2 → 4 (149325 байт), проверка подписи и следующий
  unchanged (109 байт). Клиент не сканирует GitHub и не устанавливает при просмотре.
- Publisher вводит карточку принятого проекта и его явное размещение одновременно
  с записью пакета, сохраняя остальные серверные правки. Ключ не отправляется
  серверу. Повторно используются неизменные опубликованные файлы GitHub.
- В изолированном Linux x86_64 / Qt 6.4.2 пройдены 8 проверок каталога, 8 установщика,
  2 launcher/SDK и 15 Qt controller cases. Исправлены два явных преобразования
  JSON → QString в Lobby для сборки на Qt 6.4; смысл сравнений не менялся.
- [Живая проверка](../tools/crates-release-check/README.md) использовала настоящий
  CratesController, публичный каталог, Download/подтверждение, установочный worker,
  Downloads job и managed launch обоих опубликованных пакетов. Проверены Open/Play,
  desktop entry приложения, ожидание закрытия занятого пакета и отмена этого ожидания,
  remove/reinstall с сохранением данных. Отдельный процесс Timer нашёл PlatformHost
  после изоляции XDG, зарегистрировал виджет; его callback запустил счётчик.
- Настоящие QML-компоненты Workshop и обеих карточек отрисованы на Linux в 960×540
  с живыми подписанными метаданными. Скриншоты просмотрены, изображения и Download
  отображаются корректно, QML warnings отсутствуют. Это component preview, не снимок
  полной оболочки на портативке; локальные кадры — `build/crates-release-cycle/preview/`.
- Объединённая Windows UCRT64-сборка оболочки с `BUILD_TESTING=OFF` завершилась;
  обычный startup probe подтвердил готовность discovery/handshake/context и отказ
  личного виджета без выбранного профиля. Это отдельная проверка запуска оболочки,
  не замена Linux-пакетного или аппаратного цикла.

**Границы:** это Linux-проверка владельцев механизма, не полный графический сеанс
на портативке. ARM-пакетов нет. Новые карточки/SDK требуют обновлённых helpers;
старый allowlist не принимает новый источник и сохраняет предыдущий кеш.
Физический ввод, полный Games/Home/overlay-путь, live Fluxer/internet Artillery
и обновление между двумя разными версиями остаются непроверенными.
Устройства не подключались и не обновлялись.

> Старые «далее/следующий шаг» ниже не назначают новую работу; непроверенные
> условия остаются непроверенными.

Согласованный следующий шаг после [CRATES-76](CRATES76_INSTALLER.md).
Перед реализацией перечитаны актуальные #145–148. Это рабочий список, а не
объявление готовности всего Crates.

- [x] Подписанный каталог на существующем сервере: только метаданные, пакеты в GitHub Releases.
- [x] Один запрос при входе в Apps → Crates, snapshot/delta/unchanged, атомарный кеш.
- [x] Проверка подписи, ревизии, размеров, источников и схемы до обновления витрины
  и разрешённых пакетов. Ошибка/офлайн сохраняет последнюю корректную версию.
- [x] Публикация без дополнительного согласования уже одобренных проектов;
  отзыв версии/проекта не удаляет установку или данные.
- [x] Отдельные закреплённые рецепты Hextris, Breakout и Qalculate!, исходники,
  лицензии и реальные архивы. Никаких команд установки из метаданных.
- [x] Связь с существующими Download/Play/Open, версиями и Downloads; для непроверенной совместимости — явное подтверждение.
- [x] Проверки delta, неизменившейся ревизии, повреждения/подмены, офлайна и
  конфликтов; отсутствие сетевых запросов при старте и вне Crates.
- [x] Сборка и доставка на доступные портативки, установка и запуск новых примеров,
  снимки фактического интерфейса; физическая приёмка отдельно.
- [x] PROJECT_STATUS, CHANGELOG, план, commit/push с точными границами результата.

Не расширять этот блок до отзывов, донатов, модульного SPI, общего магазина Linux
или полной совместимости всех Armada-устройств. Не повторять пройденные проверки
CRATES-76 без изменения соответствующего механизма.

## Проверено до доставки

- На ARM прошли `crates_showcase`, `crates_installer`, `crates_catalogue`.
  Последний включает две изменённые карточки, перестановку ящиков, отзыв релиза,
  конфликт/откат ревизии, повреждённую подпись/изображение, неизвестный cursor,
  офлайн с сохранением кеша и конкурентную блокировку. Тест контроллера проверяет
  отсутствие запроса при загрузке кеша, один запрос на вход и отсутствие задач установки.
- `https://crates.abysstail.art/v1/catalogue`: реальная подписанная ревизия 1,
  4946 байт полного ответа, 109 байт unchanged. Сервис не раздаёт игровые архивы.
- Все три новых ARM64-архива собраны. На Odin ELF-зависимости доступны;
  это ещё не доказательство запуска/игровой приёмки. Qalculate! занимает около
  4 МБ при скачивании и 11 МБ после распаковки, без второго Qt/browser runtime.
- Изменения серверного каталога не снимают ограничения #147/#148: модульный SPI,
  все устройства/архитектуры, полноценные сеансы и физические кнопки не закрыты.
