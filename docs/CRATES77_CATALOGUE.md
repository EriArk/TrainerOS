# CRATES-77 — обновляемый каталог и оставшиеся примеры

Согласованный следующий шаг после [CRATES-76](CRATES76_INSTALLER.md).
Перед реализацией перечитаны актуальные #145–148. Это рабочий список, а не
объявление готовности всего Crates.

- [x] Подписанный каталог на существующем сервере: только метаданные, пакеты в GitHub Releases.
- [x] Один запрос при входе в Apps → Crates, snapshot/delta/unchanged, атомарный кеш.
- [x] Проверка подписи, ревизии, размеров, источников и схемы до обновления витрины
  и разрешённых пакетов. Ошибка/офлайн сохраняет последнюю корректную версию.
- [x] Публикация без дополнительного согласования уже одобренных проектов;
  отзыв версии/проекта не удаляет установку или данные.
- [x] Отдельные закреплённые рецепты Hextris, Breakout и Qalculate!, исходники,
  лицензии и реальные архивы. Никаких команд установки из метаданных.
- [x] Связь с существующими Download/Play/Open, версиями и Downloads; для непроверенной совместимости — явное подтверждение.
- [x] Проверки delta, неизменившейся ревизии, повреждения/подмены, офлайна и
  конфликтов; отсутствие сетевых запросов при старте и вне Crates.
- [x] Сборка и доставка на доступные портативки, установка и запуск новых примеров,
  снимки фактического интерфейса; физическая приёмка отдельно.
- [x] PROJECT_STATUS, CHANGELOG, план, commit/push с точными границами результата.

Не расширять этот блок до отзывов, донатов, модульного SPI, общего магазина Linux
или полной совместимости всех Armada-устройств. Не повторять пройденные проверки
CRATES-76 без изменения соответствующего механизма.

## Проверено до доставки

- На ARM прошли `crates_showcase`, `crates_installer`, `crates_catalogue`.
  Последний включает две изменённые карточки, перестановку ящиков, отзыв релиза,
  конфликт/откат ревизии, повреждённую подпись/изображение, неизвестный cursor,
  офлайн с сохранением кеша и конкурентную блокировку. Тест контроллера проверяет
  отсутствие запроса при загрузке кеша, один запрос на вход и отсутствие задач установки.
- `https://crates.abysstail.art/v1/catalogue`: реальная подписанная ревизия 1,
  4946 байт полного ответа, 109 байт unchanged. Сервис не раздаёт игровые архивы.
- Все три новых ARM64-архива собраны. На Odin ELF-зависимости доступны;
  это ещё не доказательство запуска/игровой приёмки. Qalculate! занимает около
  4 МБ при скачивании и 11 МБ после распаковки, без второго Qt/browser runtime.
- Изменения серверного каталога не снимают ограничения #147/#148: модульный SPI,
  все устройства/архитектуры, полноценные сеансы и физические кнопки не закрыты.

## Доставка и реальные проверки, 18 октября

- [Реализация f084779](https://github.com/EriArk/TrainerOS/commit/f084779),
  [пакеты и соответствующие исходники](https://github.com/EriArk/TrainerOS/releases/tag/crates-examples-20261018).
  Это тестовые пакеты, не версия операционки. Финальная поправка входа в ящик
  сделана отдельным коммитом вместе с этим отчётом.
- Серверная ревизия 2 содержит пять проектов. Переход 1 → 2 проверен настоящим
  delta-ответом 4211 байт с восстановлением и проверкой подписи; unchanged —
  109 байт. У сервера нет закрытого ключа подписи или игровых архивов.
- На Odin и Flip установлена одна сборка SHA-256
  `e639b01cd73c6681ae8d58183443398a08612686c0c540ffde13913a7ed79c9c`.
  Контрольные суммы установленных helpers совпали с исходниками. SQLite:
  integrity_check=ok, история до/после доставки совпала, ошибок QML нет.
- На обоих устройствах через Download и подтверждение совместимости установлены
  Hextris, Breakout и Qalculate!. Все пять примеров имеют активные receipts,
  все пять задач завершены как Installed. После проверок приложения закрыты.
- Hextris отрисовывает игровое поле и принимает ввод; на Odin зафиксирован счёт 9.
  Breakout запускает раунд, рисует мяч и двигает ракетку (ввод через XTest).
  Qalculate! на Odin вычислил 887 + 2 = 889, на Flip — 8 − 7 = 1.
  Штатный WM_DELETE каждого приложения возвращает в выбранный каталог Crates.
- После восстановления Crates при запуске оболочки Odin сетевых запросов не было.
  Открытие первого ящика выполнило один запрос, результат unchanged revision 2.
  На Flip первый такой вход получил snapshot revision 2. Фонового polling нет.
- Повторная ARM-проверка окончательных Python helpers: 8 тестов установщика и
  7 тестов каталога прошли. Qt-проверка crates_showcase пройдена до финальной
  трёхстрочной поправки входа; эта поправка собрана и проверена на обоих устройствах.
- Локальные доказательства (не публичные артефакты):
  `work/crates77/{odin,flip}-final.json`, `work/crates77-entry/*-verification.json`,
  `work/crates77/final-python-check.log`, `work/crates77/live-delta.json`,
  `work/evidence/ra56-{odin,flip}/crates77-*.png`.

Это ограниченная проверка установки, запуска, ввода и возврата. Физический
геймпад, прослушивание звука, полноценные сеансы/прохождение, остальные Armada
модели и архитектуры не приняты. Статус совместимости пакетов намеренно остаётся
неподтверждённым до этой приёмки. Odin оставлен с громкостью 0%.
