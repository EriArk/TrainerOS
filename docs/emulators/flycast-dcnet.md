# Dreamcast native Online / DCNet — 26 октября 2026

**Реализован отдельный Online (in-game) в GameHub Lobby.** Владелец принял ручной
выбор комнаты внутри игры, как у PSP. Исследование с вопросом владельцу ниже по
истории заменено этой реализацией. Состояние установки и наблюдаемые проверки
записываются в конце документа; запуск приложения не означает состоявшийся матч.
R039 остаётся частичным: более широкое покрытие сервисов и 3–4 arcade кабинета
этим не завершены. [GGPO](flycast.md) и [cabinet link](flycast-cabinet.md) сохранены.

## Путь игрока

Для распознанного диска в Lobby есть отдельный **Online (in-game)**. Два участника
подтверждают готовность, хозяин нажимает Start. У каждого запускается собственная
консоль с подготовленным DCNet; затем игроки выбирают Online и одну комнату в самой
игре. Подсказка прямо сообщает об этом. Игровой аккаунт/ключ, если он нужен сервису,
создаётся средствами игры и остаётся в собственной VMU. Fluxer ведёт приглашение
и общение, Flycast/DCNet — игровой трафик. Ручных IP, маршрутизатора и настройки VPN
для этого пути нет. DCNet требует интернет; режим не объявлен offline Nearby/LAN.

Потеря Lobby не закрывает уже запущенную игру и не меняет звонок/микрофон. Восстановление
матча остаётся в игре; автоматического Rejoin/запуска при появлении в Lobby нет.
Двухместное ограничение относится к текущему координатору запуска TrainerOS, а не
к максимальной ёмкости внешнего игрового сервера или конкретной модели портативки.

## Владельцы и границы

- **S03 → S06:** native decoder читает внутренний product code IP.BIN. Код сверяется
  с каталогом опубликованных сервисов, локальная целостность — с package manifest.
  Имя файла и локальный player count не доказывают и не запрещают native Online.
  Поддерживаются общие disc readers CHD v5, GDI, CDI, CUE и M3U с первым диском;
  все зависимости набора участвуют в проверке content. Нечитаемый диск не получает
  capability. Выбор этого режима не заменяет Netplay/GGPO.
- **S06 → S03:** общий consent/Ready/Start, ticket/generation и проверка запуска;
  старый/чужой ready не запускает новый процесс. Успех запуска не выдаётся за матч.
- **S03 ↔ S08:** постоянный private archive владельца и exact content хранится под
  `saveBackupRoot/native-online/<owner-hash>/<content>/progress.bin`. На сессию —
  отдельная копия, эксклюзивный lock, исходный token, backup/atomic return/readback
  и lineage общего RuntimeSaveStorage. Проверяется owner/content/revision. VMU
  непрозрачны для TrainerOS: контейнер TODC1 хранит flash и восемь VMU по 128 KiB.
  Чужая VMU/обычные solo VMU не импортируются, их настройки не меняются.
- **Авария/конфликт:** crash, принудительный stop, неверный размер, изменившийся
  оригинал или отказ save guard сохраняют session directory для recovery и дают
  ошибку, не затирая исходный archive. Успешный обычный выход возвращает собственные
  изменения; следующая сессия читает их снова. Отдельного recovery UI этот шаг не добавляет.
- **S07:** штатный DCNet client upstream. Новый relay TrainerOS, cabinet endpoint
  и GGPO relay не участвуют. Доступность внешнего сервиса не гарантируется.
- **Input/Home/Exit:** существующий launch/input prefix и AdventureOverlayService,
  обычное подтверждение ручного сохранения. Native patch назначает session pad порту A;
  системные Home/exit используют общий lifecycle. Сон/крышка не проверялись.

## Runtime и каталог

Отдельный пакет `flycast-online` собирается из [Flycast 2.7](https://github.com/flyinghead/flycast/releases/tag/v2.7),
ревизия `5aa091fde632fb332c8d8c34e280d62dc951954c`, с небольшими headless-inspect и
controller-port патчами. [Воспроизводимая сборка, каталог, обновление и rollback](../../packaging/emulators/flycast-online/README.md).
Dojo `flycast-netplay`, кабинетный `flycast-lan` и установленный обычный Flatpak 2.7
не заменяются. Renderer входит в manifest; начальная поставка использует Vulkan.

71 product alias / 35 различных названий каталога получены из закреплённого
Redump DAT и [публичной документации DCNet](https://github.com/TheArcadeStriker/flycast-wiki/wiki/DCNet)
с дополнениями Flycast 2.5–2.7. Это региональные варианты и кандидаты на native Online,
не число проверенных игр. Названия сопоставляются только при генерации каталога;
пользовательские файлы определяются по внутреннему коду. Неизвестная редакция остаётся
неподтверждённой, а не объявляется несовместимой. Отсутствующие serial/service сведения
и процедура расширения записаны в README пакета. Поддержка не ограничена тестовыми
играми или Flip/Odin; внешние сервисы/редакции требуют отдельного подтверждения.

## Проверки исходников и native runtime

- Flycast save suite: повторное чтение VMU, отдельный owner, конфликт параллельного
  доступа, crash recovery, изменённый оригинал и package/content отказ — проходят.
- Shared RuntimeMultiplayer/LocalLobby: отдельный режим, интернет-only, ручной вход
  в матч, сохранение процесса при потере Lobby и отказ устаревшего ready — проходят.
- Native 2.7 собран ARM64. Чтение реальных дисков на Flip подтвердило коды ChuChu,
  Daytona, Ooga Booga, Outtrigger, PSO v2 JP, Quake III, Next Tetris и Worms World Party.
  Offline Soul Calibur/Power Stone не получили Online. Найденное расхождение имени
  Quake III в исходном DAT исправлено в генераторе; runtime не зависит от имени ROM.
- Историческая проверка Flatpak XDG окружения была исследованием; интеграция использует
  отдельный native бинарник и private config/data с изоляцией fallback внутри Flycast.
  Общие XDG_DATA_DIRS сохраняются: их подмена скрывала системный Vulkan ICD; это
  обнаружено при native запуске и исправлено до поставки.
- В container cabinet namespace case пропущен из-за запрета вложенного namespace;
  прежняя host-проверка кабинетного пути сохранена. Это не новый cabinet gameplay proof.
