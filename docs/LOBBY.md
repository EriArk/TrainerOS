# Лобби — действующий контракт

Lobby находится в GameHub. Игровые входы — Lobby и строка Lobby/Create Lobby на
Home; не добавлять снова отдельные мультиплеерные меню повсюду. Служебные группы,
членство и сообщения использует Fluxer. Local без Fluxer отложен.

## Каталог и комнаты

- Слева категории/поиск/фильтры, справа горизонтальные карточки 2×3 постранично.
  Аватар и небольшой ник создателя слева; название комнаты, игра, занятые/все места,
  время сбора. Если игры нет — Choosing Together вместо названия игры, не категория.
  Есть Party Games, Competitive, Other Games. Категорию выбирает создатель.
- Пользователи автоматически вступают в каталог-комьюнити Fluxer; бот обслуживает
  каталог. Установщик такого бота для чужих комьюнити — позднее.
- A на категории переводит в карточки, B возвращает в левую колонку; вверх до
  конца переводит на Create/My Lobby. Та же функциональность доступна пальцем.
- Ручной Refresh — заметная компактная голубая кнопка справа снизу, недоступная
  во время загрузки. С джойстика обновление доступно через Select → Refresh.
  Существующее периодическое обновление раз в минуту сохранено; частота фоновых
  обращений к Fluxer не увеличена. После сетевой ошибки общий клиент повторно
  загружает каталог вместе с данными Social.
- My Lobbies — вертикальная всплывашка среднего размера с компактными карточками,
  информацией/аватарами, крестиком и Create справа сверху. Открывается и из Home.
- Несколько комнат допускаются для расписания, Ready одновременно только в одной.
  Создание через wizard: применить или закрыть; никаких сохраняемых черновиков.
  Не предлагать привязку произвольного существующего group conversation.
- Leave хозяина передаёт управление; когда других игроков нет — закрывает лобби.
  Полное закрытие отдельно. Очистить служебную группу у участников через Fluxer.
  В Social не показывать её с самого начала: фильтр по устойчивой принадлежности,
  не по названию. Личные/обычные группы этим не удаляются.

## Подготовка и запуск

Game Picker — полноценная всплывашка с категориями/упрощённым Games list,
выбором вида мультиплеера и несколькими кандидатами для голосования.
Preparing под аватаром означает «ещё не Ready», не процент технической подготовки.
При нажатии Ready кнопка меняет вид, показывает spinner и недоступна до ответа;
затем разрешено Not ready. Когда готовы все, у хозяина появляется крупная Start
справа от карточки игры. **Автоматического запуска по all-ready нет.**

Все запуски, включая solo, используют общее затемнённое окно с этапом подготовки,
крутилкой и отменой. Подсказки управления только из реальных подтверждённых данных.
Согласие/несохранённая игра, доступность контента, runtime/admission и own saves
проверяются раздельно. [Реализация/незакрытая приёмка](LOBBY63_PREPARATION.md).

Согласие на встречу создаёт локальное напоминание за 15 минут; после пробуждения
показать/озвучить, если сбор ещё не начался. Будить устройство по настройке — позже.
Свёрнутых приглашений-кругляшей нет: они ожидают в уведомлениях.

## Общение и зрители

Игроки и зрители — роли в общем Fluxer-разговоре. В обычном чате фильтруем зрителей,
в зрительском — игроков. Под чатом тонкая строка количества зрителей; раскрытие
занимает правую колонку, плотный stream-style список. Для игроков он read-only.
Хозяин/игроки не превращаются в зрителей комнаты; отдельный Watch и переход роли
ещё отложены. Голос используют существующий, без второго самодельного сервиса.

Lobby-сообщения: текст, emoji, файлы через +/file picker и реальные лимиты Fluxer.
Нет отдельных GIF, картинок и voice-message controls. Во время игры тёмный mini-chat
без лишних подсказок; [HUD и входы](LOBBY64_ENTRIES_HUD.md).
