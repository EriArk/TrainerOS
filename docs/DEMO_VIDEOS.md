# Короткие демонстрации TrainerOS

19 октября 2026: владелец выбрал короткие тематические видео вместо одного
длинного обхода. Odin — красная тема, Flip — бирюзовая; разные цвета помогают
различать участников в будущем мультиплеерном видео.

## Проба Home — записана

На Odin выбран Pokémon Emerald с существующим адаптером через избранное:
Home → X Quick Apps, перемещение между приложениями → закрытие → Y Recent/★,
переключение на недавние игры и перелистывание → Home. Emerald добавлен
в избранное для выбора на Home; игру и сохранения для этой съёмки не запускали.

Локальный результат: `work/launch80/traineros-home-red-20s.mp4`, 20 секунд,
1280×720, H.264/YUV420p, контейнер 30 кадров/с, 1 835 787 байт, без аудио.
SHA-256: `8396e8fbccfa093ceda5437dbb47bb8447a22c74eaa9934a35278b86c7dfd9da`.
Файл полностью декодирован без ошибок; просмотрены кадры всех этапов и финал.
Видеозапись остаётся локальной, не включается в Git и не опубликована.

Захват — существующий Gamescope/PipeWire helper с проверенным appid оболочки;
production helper, оболочка и композитор не изменялись. FFmpeg кодирует на устройстве.
Источник присылает кадры при перерисовке: последний полученный кадр удерживается
до следующего с сохранением реального времени. 600 выходных кадров не означают
600 уникальных кадров или доказательство стабильных 30 fps во всех переходах.
X11-захват давал чёрный экран, прямой KMS — повреждённое изображение; эти пробы
не используются. Захват игры, системного звука и двух экранов ещё не проверен.

## Games — записан после одобрения Home

На бирюзовом Flip записаны 35 секунд: коллекции и ряд платформ → Super Mario →
колесо с Mario Golf, Mario Kart 64 и Mario Kart DS → список с перелистыванием
страницы → полки → сетка → возврат к колесу с Mario Kart 64. Переключение вида —
штатным R3; навигация — событиями контроллера. Это настоящий интерфейс установленной
сборки, без изменения приложения, макетов или запуска игр.

Локальный файл: `work/launch80/traineros-games-turquoise-35s.mp4`, 35 секунд,
1280×720, H.264/YUV420p, 30 кадров/с в контейнере, 3 854 985 байт, без аудио.
SHA-256: `95c54554940b5de248a9a6d3d1809b9ae04b0d73bea6b2f87a84cb640193cf39`.
Проверены полное декодирование и кадры всех этапов. Тот же Gamescope/PipeWire-захват:
1050 выходных кадров, 276 полученных кадров с учётом подготовки; неподвижные кадры
удерживаются до следующей перерисовки. Это не замер производительности интерфейса.
После записи оболочка продолжает работать, процессы записи завершены, звук выключен.
Файл остаётся локальным и не опубликован. Odin остаётся красным; предыдущий Home-ролик
сохранён отдельно. История первой видеопробы —
[`4f7ebfd`](https://github.com/EriArk/TrainerOS/commit/4f7ebfd).

Следующий предложенный ролик — GameHub: My Story, таймлайн, галерея и достижения.
Остальные сценарии ниже остаются предложениями до их съёмки.

## Серия — Home и Games отсняты, остальные предложены

Для двух участников предложены соседние экраны или монтаж с переключением
между красным и бирюзовым. Перед Lobby нужна репетиция точного сценария
голосование → запуск → два управляемых игрока. Перед публичной версией отдельно
выбрать безопасное содержимое уведомлений/переписки и кадры без личных данных;
эта проба не означает публикацию. Не подменять рабочий интерфейс макетами,
синтетическими сообщениями или выдуманными достижениями.
