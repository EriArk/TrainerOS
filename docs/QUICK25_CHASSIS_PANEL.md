# QUICK-25 — Quick Apps как растущая панель корпуса

16 октября 2026. Владелец отверг иконки, стоящие над полкой QUICK-24.
Нужна панель с кнопками, вырастающая из корпуса так же, как ушки.

- X открывает по центру снизу цельную панель материала/цвета корпуса.
  Её основание неподвижно на нижней рамке; изменяется высота, а не положение
  отдельной полки. Кромка соединяется с рамкой без нижнего шва/зазора.
- Приложения — квадратные объёмные кнопки в углублениях внутри панели,
  с настоящими иконками, подписями и индикаторами работы. Возвращена ранее
  использовавшаяся геометрия клавиш 54/54 и гнёзд 64/64; нет левитирующего ряда.
- Ширина по количеству приложений с ограничением экрана; переполнение
  прокручивается и следует за выбором. Одиночная кнопка центрирована.
- Ушки QUICK-24 (X поверх, жёлтый Y справа), усиленное наложение, круглая Y
  внутри своего контура и 174 × 36 сохранены. Панель Recent games не переделана.
- Общие X/Y, A/B/Select, касания, меню, процессы приложений и reduced motion
  сохранены. Установка избранных для проверки из QUICK-24 остаётся настройкой
  устройств: пять на Odin, шесть на Flip, без изменения общих defaults.
