# GAMES-40 — Shelves

Согласовано владельцем 16 октября после принятия List: два ряда настоящих
обложек ScreenScraper на горизонтальных полках, вертикальная прокрутка.
Начальная плотность — пять игр в ряду; оценить на настоящем экране.
Отдельной правой информационной панели нет. Полки используют материал корпуса,
мягкие тени и скосы. Пропорции обложек сохраняются; выбранная чуть выступает
вперёд, с лёгким светящимся контуром. Название под обложкой, длинное у выбранной
игры прокручивается с паузой; reduced motion — многоточие.

Заглушки: цветные жанровые иллюстрации с крупными силуэтами, мягким объёмом
и умеренной детализацией для маленькой обложки. Фэнтезийные острова/замки/
кристаллы сохранены; добавлены гонки, спорт, космос, головоломки и экшен.
Неизвестный жанр получает нейтральный мотив. Жанр берётся только из метаданных,
не угадывается по названию игры. Внутри группы вариант определяется устойчиво
по ID игры: не меняется от сортировки, фильтра и перезапуска. При изменении
самого жанра может смениться группа; случайные совпадения соседей допустимы.
Название и платформа накладываются интерфейсом. Настоящая обложка заменяет
заглушку; битая картинка возвращает её. Поля screenshot/titleshot/fanart/mix не подставляются вместо обложки.

Управление: влево/вправо — соседняя обложка, вверх/вниз — соседний ряд,
вертикальный свайп — полки. A запускает выбранную игру, Select — существующие
действия. R3 последовательно Wheel → List → Shelves → Wheel. Сохраняются
контекст, ID, фильтры, Home, L2/R2 и глобальные X/Y. Grid остаётся следующим
отдельным экраном после обсуждения.

Порядок: общий выбор вида/навигация → виртуализированные полки/обложки →
графика → проверки состояния, границ и UI на разных размерах → доступные
Odin/Flip с реальными обложками → документация, commit/push.

### Граница старых метаданных

Полки предпочитают boxart, затем image (сюда ScreenScraper сохраняет box-2D/3D),
затем прежний cover, исключая ссылки, явно помеченные screenshot/titleshot/
fanart/mix. Автоматического распознавания содержимого картинки нет: некоторые
старые записи владельца поместили скриншот непосредственно в image. Эти записи
сохранены без переименования/перезаписи; UI показывает указанный пользователем
материал. При отсутствии жанра используется neutral, название игры не служит
основанием угадать RPG и т. п. Это ограничение исходных метаданных, а не
подтверждение получения новых обложек для всей библиотеки.
