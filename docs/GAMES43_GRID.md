# GAMES-43 — Grid со скриншотами

Согласовано 16 октября: Grid должен отличаться от Shelves. Сейчас широкие
карточки со скриншотами, название под изображением, вся область Games без
бокового информационного блока. Плотность подбирается по реальным кадрам, адаптация к размеру
рабочей области, вертикальная прокрутка. Лёгкая объёмная рамка и подсветка;
никаких полок, корешков и вертикальных коробок. Скриншоты сохраняют пропорции.
При отсутствии — тематический фон и название/логотип из имеющихся ресурсов.

Общая игра и её ID, фильтры, прямой A, Select, возврат, L2/R2 и Home сохраняются.
R3: Wheel → List → Shelves → Grid. View хранится в существующей области профиля.
План: общая навигация/сохранение → карточки → проверки ID, границ и прокрутки →
реальные скриншоты Odin/Flip → документация, commit/push.

## Оформление и плотность

Рамки следуют пропорциям изображения, подпись стоит сразу под рамкой.
Пять или шесть карточек в ряд по доступной ширине; минимум два видимых ряда.

## Отложено до очереди настроек

Владелец просит настройки отображения библиотеки: выбирать, что показывать,
включая скриншоты или красивые названия/логотипы, подписи и другие элементы.
Точные переключатели и их области действия обсудить при системном блоке настроек.
Сейчас не добавлять меню настроек и не считать этот пункт реализованным.
Это отдельная будущая работа; текущая поставка использует скриншоты.

Уточнение владельца: отвергнуты растянутые поля вокруг маленького скриншота.
Рамка должна облегать изображение по его настоящим пропорциям; пустые боковые
плашки не допускаются. Количество колонок само по себе эту проблему не решает.

Плотность уточнена владельцем: 5–6 карточек в ряд по доступной ширине,
число видимых рядов — по высоте. Подпись снизу, рамка по пропорциям изображения.

## Реализация и проверка — 16 октября

Добавлен LibraryGrid с виртуализированными карточками, вертикальным свайпом и
стрелками. Ввод перемещается по фактическому числу колонок. Инерция свайпа
не перехватывает программный выбор; изменение размеров учитывает originY.
Скриншот берётся из явного artwork.screenshot; при его отсутствии используется
имеющийся тематический фон и логотип/название. Поле image не считается
автоматически скриншотом: в старых метаданных оно также содержит обложки.
Видео в карточках не запускается. Отдельного окна настроек не добавлено.

Native/ARM собраны. 20 SeriesTests прошли: границы/неполный ряд, смена колонок,
сохранение Grid и выбранного ID, пустой фильтр и прямой запуск через адаптер.
Финальный UI smoke PASSED: цикл четырёх видов R3, 101 игра с ограниченным числом
делегатов, свайп без запуска, последний ряд, рамка без полей вокруг изображения,
960×540/1920×1080/1280×800, возврат первой выбранной игры после resize и пустой вид.
Первая широкая компоновка с полями отвергнута; заменена рамкой по изображению.
