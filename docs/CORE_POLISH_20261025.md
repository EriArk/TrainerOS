# Core: медиа, звук, коллекции и проверка системы — 25 октября 2026

Принятый владельцем блок в `main`; SDK, OTA, игры Crates и multiplayer остаются
в отдельных задачах. Этот документ отделяет реализованный объём от полной
приёмки #65/#29, #245, #199, #80/#81.

## ScreenScraper и видео

- Missing-only сначала проверяет выбранные локальные поля и пригодность медиа.
  Полностью оформленная игра пропускается до авторизации API и чтения ROM для хеша.
- Видео включено в профиль загрузки по умолчанию. Оно сохраняется локально через
  прежний ограниченный загрузчик; настройки скачивания и показа независимы.
- Записанные поля получают источник и хеш значения. Refresh и исправление
  сопоставления заменяют только неизменённые поля ScreenScraper. Ручные правки,
  названия владельца и старые данные без доказанного происхождения сохраняются.
  При смене ID удаляются устаревшие provider-owned поля, даже если новый ответ
  не содержит их замены. Локальные файлы при этом не удаляются.
- В панели выбранной игры есть `Correct this game's match`: ранее принятый ID
  не обходит явный выбор. Это каталог оформления, не разрешение на работу с сейвом.
- Превью запускается после задержки 1,5–3 с, по умолчанию без звука. Звук и задержка
  сохраняются для Trainer в Settings → Personalization. Скруглённая маска сохраняет
  пропорции. Прежние остановка при навигации/оверлее/запуске игры и fallback картинки
  при неподдерживаемом видео остаются обязательными.

## Start → Volume → Sound

Одно компактное окно с вкладками Sources / Microphones / Output device.
В Sources показаны реальные системные потоки, с отдельными уровнем и mute.
Микрофоны имеют уровень, mute и выбор системного входа по умолчанию. Мониторы
выходов не выдаются за микрофоны. Список обновляется по событиям pactl во время
открытого окна; последнее положение перетянутого ползунка ставится в очередь.

L2/R2 меняют вкладку, вверх/вниз — строку, влево/вправо — уровень, A — mute
или выход, Select — основной микрофон. Те же действия есть пальцем.
Перед записью поток повторно проверяется по идентичности: исчезнувший или
переиспользованный индекс не должен менять звук другого приложения.

Границы: это управление потоками PipeWire/PulseAudio, а не виртуальные категории.
Если игра/музыка/голос смешаны приложением в один поток, разделить их здесь нельзя.
Выбор микрофона не начинает запись и не меняет согласие на микрофон звонка;
провайдер с явно выбранным собственным устройством может не следовать default.

## Автоматические коллекции

Две лёгкие колонки: условия слева, результат справа. Вложенные группы All / Any /
None, поля title/system/genre/developer/publisher/players/played/favorite,
текстовые сравнения и число игроков. Preview & exceptions позволяет включить
или исключить конкретную игру независимо от правил. Исключение имеет приоритет.
Неизвестные метаданные не превращаются в положительное совпадение через отрицание.

Правила и исключения остаются черновиком до Save. Данные отдельны для Trainer,
ID игр стабилен, ROM/сейвы не перемещаются. Старые определения v1 читаются без
изменения их условий; новое сохранение v2 сохраняет неизменённые определения.
Неизвестная версия/некорректное дерево блокирует запись исходного файла.

## Settings → System → System health & game setup

Системы группируются по существующим runtime-адаптерам и играм библиотеки.
Проверка файлов и требований прошивки выполняется в рабочем потоке без запуска
игры. Изменившаяся регистрация не получает устаревший результат. Есть повторное
обнаружение, переход к Properties игры, локальная справка и открытие отчётов в Files.
`Setup checked` подтверждает требования текущего адаптера, не совместимость игры.

Support archive — локальный TAR с ограниченным JSON: версии Qt/SDL/ОС,
архитектура, агрегаты систем, наличие контроллера, свободное место и результат
readonly SQLite quick_check. Собирается по белому списку; не включает названия игр,
пути пользователя, ROM/BIOS/сейвы, учётные данные, содержимое сообщений или сырые
логи. Никуда автоматически не отправляется. Старый input-report остаётся отдельным.

  Оригинальный тестовый MPEG-4 сгенерирован host ffmpeg и передан в контейнер,
