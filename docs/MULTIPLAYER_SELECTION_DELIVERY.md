Неоднозначности плана: Scud Race Plus требует проверки родительского архива,

самостоятельно; отсутствующие или неоднозначные издания оставить явно отмеченными.
Локальная опись серверных файлов — вспомогательный материал, не доказательство
правильной ревизии или работоспособности. Пути, хеши личных файлов и результаты
частного переноса остаются вне публичного Git.

## Разрешение на освобождение места

20 октября владелец заранее разрешил очистить мусор и удалить несколько
установленных игр на Flip/Odin, чтобы разместить согласованную подборку.
Повторное разрешение на эти действия не требуется. Выполнить после подключения
устройств, по фактическому дефициту места: сначала ненужные временные файлы
и остатки установок, затем необходимое количество игр вне целевой подборки.
Предпочитать игры, исходные файлы которых подтверждены на сервере.

Сохранить личные сейвы, save states, настройки, аккаунты, скриншоты,
необходимые BIOS/firmware и рабочие компоненты системы. Не трогать активную
игру/транзакцию сохранения. Серверные оригиналы не удалять. Перед удалением
проверить точные пути и назначение файлов; локально записать удалённые позиции
и освобождённое место. Фактическое освобождение места и оставшаяся приёмка отражены выше.

## Порядок доводки

1. Сопоставить каждую игру с реальным режимом: совместная игра одной консоли
   с отдельными контроллерами, link, штатная сетевая игра либо общий Remote Play.
   Не выводить транспорт из количества игроков. Для lightgun, инструментов,
   второго экрана и других специальных контроллеров отметить реальные требования.
2. Использовать существующие интеграции и утверждённые runtime/core/build,
   общие лобби, запуск и привязки управления. Исправлять общий механизм при
   общей причине; не создавать отдельный сетевой протокол для каждой игры.
3. Проверять из TrainerOS: лобби → выбор игры/режима → готовность →
   Start владельца → подключение → ввод обоих игроков → штатное завершение.
   Сохранения участников и нормальный выход должны оставаться защищёнными.
   Пройденные ранее проверки повторять только при изменении затронутого кода,
   новом сбое либо конкретном пробеле в доказательствах.
4. Вести результат по игре, режиму, изданию, сборке и устройству:
   перенесено / маршрут подготовлен / парная игра проверена /
   блокируется конкретной причиной / ожидает внешней проверки.
   Одна успешная игра не сертифицирует всю платформу; LAN не доказывает
   соединение через разные сети.

Наличие Xbox 360 и PS3 в новом списке сохраняется как запрос на эти игры
в подборке и последующую оценку их маршрутов. Оно не означает готовность
эмулятора или мультиплеера и не добавляет Switch. Более раннее исключение PS3
из multiplayer-плана не должно приводить к молчаливому удалению этой позиции.
Если нужного маршрута нет либо устройство его не тянет, записать точный пробел
и обсудить вариант, не обещать универсальную совместимость.

Обычный PSP остаётся достаточным; закрытые партии и полный каталог передачи
одного контроллера не возвращаются в работу. Couch означает одновременные
отдельные контроллеры. Две копии PS2 на одной портативке не используются.
При трудных NAT сохраняется ранее согласованная отсрочка.
