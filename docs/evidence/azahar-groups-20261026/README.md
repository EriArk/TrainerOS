# 3DS Lobby groups — 26 октября 2026

## Результат

2–4 независимые консоли через штатный Azahar 2126.2 Room/RoomMember и существующий
защищённый транспорт. Отдельные ключи/адреса гостей и UDP sockets, фиксированные
места, общий допуск к игре, ограниченное завершение всех helpers. Собственные
NAND/SDMC и обычные настройки не заменяются. [Контракт/обновление](../../emulators/azahar.md#lobby-groups--26-october-2026).

## Доставка

Пока не выполнена. Перед установкой сверить текущую оболочку и все native manifests,
сохранить собственные настройки/SQLite/игровую историю и прежний пакет каждого устройства.
Обновление должно включать native binary, room helper, manifest и shell вместе.
Не заменять профили других платформ, DS helper или пользовательский NAND/SDMC.
Откат — вернуть сохранённые shell и пакет целиком при закрытой игре; личный storage
поверх старой копии не восстанавливать.

## Границы

Нет новой игровой сертификации, реальных разных внешних сетей или WFC.
Профиль DS остаётся на двух участниках: его сетевые seeds/inputs/checkpoints/
согласованный возврат своего сейва требуют отдельного расширения. Четыре локальные
DetMP-машины не доказывают сетевую группу. Старые парные описания 3DS относятся к
предыдущему пакету; другие платформы и пользовательские переопределения сохранены.
