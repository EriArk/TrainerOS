# Обновление Crates и общего SDK — 26 октября 2026

Владелец явно разрешил обновление игр и проверки Odin/Flip. Доставка сохраняет
текущую оболочку, Local Lobby и поддержку форматов из параллельной работы.

## Происхождение

- Интеграция оболочки: `54333929` (`785cb124` + Backend `61a8cfb3`).
- ARM64-сборка включает сохранённые изменения исходников установленной оболочки;
  это не чистая сборка одного Git-коммита. Архив исходников и хеши наложения
  сохранены вместе с бинарником на существующем сервере.
- Golf 0.1.23: `ced2e80`; восемь аркад 0.1.3 и Artillery 0.1.4: `5926385`.
- ARM64: Qt 6.11.2, GCC 16.2.1, изолированный Podman на Odin.

## Проверки сборки

Оболочка собрана. Account и Platform SDK прошли после исправления двух старых
тестов: сравнение раскладки теперь использует ID и все страницы, а не прежнее
число страниц и первый виджет. Продуктовая раскладка не менялась.

SDK network: 5 passed, 0 failed, 1 skipped; 16 участников подключались через
реальные TLS helper-процессы. Пропущен отдельный Godot avatar fixture, которому
нужны внешние assets/runtime. Это не игровой матч шестнадцати портативок.
Аркады: 43 passed. Artillery: 10 passed. Сетевые тесты выполнялись в отдельном
network namespace и не занимали живые порты пользовательской сессии.

## Установлено и проверено

Odin и Flip получили один бинарник из `binary.json`: [Odin SDK](odin-sdk.json),
[Flip SDK](flip-sdk.json). Проверены хеш живого процесса, автоматический перезапуск
и capabilities `network.group`, `play.scorecards`, `account.identity`.
На каждом устройстве сохранены старый бинарник, настройки и SQLite backup.
Дубликаты нового бинарника из временного staging удалены после проверки.

Все десять игр обновлены и запущены на обоих устройствах. Их отдельные
installation/launch receipts и шесть просмотренных кадров находятся в Crates,
`docs/evidence/devices-20261026/README.md` ветки `codex/golf-backend`.
Golf на обоих показал Connected to TrainerOS; на Flip для этого потребовалась
отдельная проверка после первого короткого запуска. Игры завершены управляющим
launcher через SIGTERM, обе оболочки оставлены работающими, Odin — с громкостью 0%.

Для следующей сборки использовать совмещённые исходники и сохранённое наложение
Local Lobby/форматов. Прежний каталог `traineros-apps-build/source` намеренно
не перезаписывался: повторная сборка только из него потеряет новые SDK API.

## Открытая приёмка

Короткие проверки запуска не заменяют физические кнопки/звук, длительный FPS,
полный Ready/Start/реванш и разные интернет-сети. Общий результат остаётся
peer-confirmed: серверная верификация физики и полноценный античит не реализованы.
Публикация каталога и GitHub не входят в эту доставку.
