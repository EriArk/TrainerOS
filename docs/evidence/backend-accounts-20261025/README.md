# Accounts — серверная реализация, 25 октября 2026

Источник: `codex/backend-foundation`, после `7bcc8d9`.
Владелец подтвердил Fluxer-only вход без отдельного пароля TrainerOS и отдельное
OAuth-приложение **TrainerOS**. [Реализация и контракт](../../../services/backend/accounts.md).

## Проверено

- [34 теста](tests.txt) прошли на сервере: общая инфраструктура и Accounts,
  отдельная настоящая PostgreSQL, контейнер без внешней сети и без service volume.
  OAuth заменён контролируемым provider и локальным HTTP fixture.
- Проверены стабильный Player UUID по Fluxer subject, независимость чужих игроков,
  конкурентное создание identity/claim/refresh, revoke/expiry/suspension, browser
  cookie/state, PKCE, proof владения попыткой, обязательное подтверждение кода,
  ограничение пяти ошибок, отказ чужому Origin, запрет provider redirects,
  размеры запросов/ответов и отсутствие секретов в ошибках/сохранённых сессиях.
- Повтор refresh фиксирует отзыв до ответа 401; другие устройства остаются
  активными. Audit и `account.session_revoked` фиксируются вместе с отзывом.
- [Проверка контрактов](contracts.txt): architecture-draft.3, OpenAPI/JSON Schema,
  ссылки всех модулей, 48 логических сущностей и 36 структурных граничных примеров.
  `LoginAttempt.verification_code` возвращается только инициирующей оболочке,
  не попадает в authorization URL или страницу подтверждения.
- [Установленный API](server-check.json): readiness=200 после трёх миграций;
  реальные auth/session handlers присутствуют в OpenAPI. Без настройки OAuth
  они возвращают `provider_not_configured`, capabilities пустой.
- [Backup/restore](restore-check.txt): восстановление в одноразовый контейнер без
  сети, точное совпадение всех version/checksum с текущей БД. Перед обновлениями
  сохранены резервные копии. Рабочая БД при проверке восстановления не менялась.
- Lobby directory остаётся active с прежним временем запуска 24 октября;
  его приложение, credentials, конфигурация и процесс не менялись.

Установленный runtime image:

## Что не подтверждено и почему вход выключен

На сервере найдены credentials только для **TrainerOS Lobby Directory**;
публичные metadata этого приложения содержат scope bot и пустой список redirect URI.
Встроенный браузер вошёл под тестовым пользователем. Владелец выбрал отдельное
приложение, но постоянный аккаунт для его регистрации пока не предоставлен через
пользовательский вход. Под тестовым аккаунтом постоянное приложение не создавалось.

Приложение **TrainerOS** ещё нужно создать в аккаунте владельца, настроить public
HTTPS origin и callback, разместить отдельные client credentials на сервере и
пройти реальный consent/cancel/relogin. В текущей поставке нет публичного ingress
и live OAuth round trip. `compose.oauth.yaml` подготовлен, но не применён.

Схемы/fixture-проверки не доказывают совместимость текущего upstream с конкретным
зарегистрированным приложением. Также не проверены реальная оболочка/SDK,
хранение на устройстве, смена локального Trainer, revocation consumers,
recovery/удаление/смена привязки, внешняя сеть и портативки. R089 остаётся открытым.
Результаты, рейтинги и экономика этим проходом не реализованы.
