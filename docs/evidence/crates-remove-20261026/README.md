# Прямое удаление Crates — 26 октября 2026

По уточнению владельца промежуточное Manage → Remove заменено красной кнопкой
с существующей иконкой корзины. Она видна рядом с Play/Update у установленного
проекта, отключена при операции с пакетом и сразу открывает подтверждение:
«Remove this project?» / «Your saves and data will be kept.»

Select открывает это же окно с контроллера. Начальный выбор — Cancel;
B/крестик закрывает окно. Подтверждённое Remove идёт в прежнюю очередь и
установщик с сохранением пользовательских данных. Скрытый вызов действия
без открытого подтверждения не ставит удаление в очередь. При открытом окне
основная кнопка Play/Update недоступна. Предупреждение для непроверенной
установки остаётся отдельным подтверждением «Install anyway?».

ARM64 CratesTests: **23 passed**, включая выбор Cancel по умолчанию, B без
операции, игнорирование скрытого вызова и постановку удаления только после
явного подтверждения. Проверка использует временные receipts и удерживает
очередь; настоящие игры для теста не удаляются. [Лог](tests.log).

Визуальный сценарий прошёл без QML warnings: [корзина рядом с Update](update-primary.png),
[прямое подтверждение](remove-confirmation.png), [результат](result.txt).
В нём виртуальный SDL Select сразу открывает подтверждение, а Confirm на исходном
Cancel закрывает его без задания в очереди. Это изолированные данные и программный
ввод, не физическая приёмка кнопок и касания.

Production-сборка (`BUILD_TESTING=OFF`) установлена и работает на **Odin 2 и Flip 2**:
`8321ec3e47f46f5efeabec38dce8f5da7b68ee39b271bb70b8345d0d425bf44d`.
[Лог сборки](build.log). Перед заменой сохранены бинарник, настройки и SQLite-backup.
Проверка прежнего SHA остановила первую попытку после параллельной доставки;
сверка всех исходников и параметров сборки подтвердила, что отличались только
шесть файлов этой правки. После сверки обновлён базовый SHA, выполнена установка,
а правка аккуратно применена также к общим исходникам сборки на Odin.

- Odin: [установка](odin-delivery.json), [проверка после UI](odin-health.json).
- Flip: [установка](flip-delivery.json), [проверка после UI](flip-health.json).

На обоих устройствах открыта обычная карточка Pocket Golf 0.1.23: красная корзина
видна, промежуточного Manage нет. На Odin программный клик по корзине, на Flip
семантический Select через X11 открыли подтверждение. Confirm на исходном Cancel
вернул к карточке с Play. После этого SHA-256 всех файлов `crates/active` и
`crates/data` совпали с состоянием до установки: 882 файла Odin, 1463 файла Flip.
Игры не запускались и не удалялись; сохранены настройки и данные каждого устройства.
Кадры устройств с именами профилей не включены в публикуемые материалы.

**Осталось:** физическая приёмка кнопок и касания. Реальная операция удаления
не повторялась на пользовательской библиотеке: её прежний установщик не изменялся,
а новая граница подтверждения/отмены проверена изолированным тестом. GitHub не
публиковался; серверная работа Golf остаётся остановленной.
