# Home / Start / Games — 26 октября 2026

Продолжение общего прогона `c0ba3834`: исправить оставшиеся сбои core/interactions,
сохранив текущий интерфейс и работу остальных веток в main.

## Изменения

- Закрытие старого маршрута локального профиля Trainer возвращает в исходный раздел. Раньше Back открывал
  устаревшее меню Home с недоступным пунктом Profile. Отмена редактирования остаётся
  отдельным первым шагом; сохранение не выполняется автоматически.
  Это совместимый маршрут `openProfile`; текущий аватар открывает отдельный
  профиль общения через `openAccountProfile`.
- Восстановление экрана истории GameHub заменяет режим и account-контекст галереи
  RetroAchievements целиком. Посещение галереи больше не меняет сохранённый экран
  адаптера при последующем возврате. Проверка принадлежности достижений аккаунту
  и игре остаётся в reconcile.
- Обновлены устаревшие сценарии Start: действия виджетов, страницы, сохранение
  выбора при закрытии Downloads/ScreenScraper, вложенные панели над клавиатурой.
  Games сохраняет открытый список и выбранную игру при переходах между разделами.
- Тест контроллера проверяет Home при отпускании, Home+X и подавление нажатий до
  нейтрального состояния. Пустой Recent не выбирает несуществующую игру; PC остаётся
  доступным входом для импорта в пустой редактируемой библиотеке.
