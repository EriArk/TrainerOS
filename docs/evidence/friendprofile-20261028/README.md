## Реализация

- Почти полноэкранный профиль: персонаж из общего пакета, выбранная сцена,
  имя, уровень, пять экспонатов, последние подтверждённые достижения,
  коллекция прохождений и явно опубликованное избранное.
- Вход из Social/лобби и по стабильному UUID; возврат сохраняет источник.
  Message/Invite используют действующие DM и Lobby. Собственные View as player
  и Sharing используют ту же серверную проекцию без обхода видимости.
- Уровень/полка по умолчанию видны вошедшим игрокам; история/достижения,
  активность и избранное скрыты. Баланс, покупки и слоты всегда исключены.
  Смена аккаунта очищает карточку и отменяет применение старых ответов.
- При числе участников больше пяти лобби использует две колонки с прокруткой.
  В игровом HUD при числе больше четырёх — два говорящих и счётчик остальных.
  Полный список сохраняет все места и возврат к выбранному игроку.
