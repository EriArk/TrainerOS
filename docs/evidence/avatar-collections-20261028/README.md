## Визуальная проверка и исправление SDK

При просмотре кадра Wave обнаружено искажение тела в Godot Compatibility:
[до исправления](odin-sdk-wave-before.png). Оно также есть в сохранённом
проверочном кадре revision 7. Поэтому первоначальный `FACIAL_RIG success=true`
не считается доказательством корректной отрисовки анимации тела.

Общий presenter теперь вычисляет корректирующие формы тела/одежды на CPU,
маршрутизируя исходные scalar-треки в независимые веса экземпляра. Пересчёт
выполняется только при изменении весов перед отрисовкой; скелет остаётся на GPU.
GLB, его хеш, исходные клипы и привязки не меняются. Другие рендереры сохраняют
GPU morphs. Проверка [сарафана](correctives-sundress.log), [бриджей](correctives-denim.log),
[гоночного](correctives-racing-classic.log) и [розового](correctives-racing-rose.log)
охватывает 128 поз восьми клипов, неизменность головы/skin, независимость
экземпляров, точный возврат нейтральных вершин и освобождение обработчика.

Исправленный checker на обоих устройствах дал по 21 кадру; крупные планы
нейтрального/эмоционального лица и Wave просмотрены. Результаты:
[Odin](odin-sdk-render.json), [Flip](flip-sdk-render.json).

## Осталось отдельно

Оценка владельцем, физические кнопки, все движения/пересечения одежды в играх,
FPS и полная новая игровая сессия не подтверждены этим проходом. Коллекция не
назначалась наградами конкретных игр/уровней. Пакеты игр не пересобирались:
исправление общего Godot presenter нужно перенести в их встроенные копии SDK.
Новая версия asset pack сама не обновляет код потребителя. Параллельный профиль
друга/Social сохранён в рабочем дереве и не входит в эту поставку.
