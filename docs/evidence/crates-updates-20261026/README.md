# Crates: Update и автоматические обновления — 26 октября 2026

## Изменение

Владелец остановил серверную приёмку Golf и запросил исправление самого Crates.
Обычный выбор версий удалён из QML, команд контроллера и меню. Карточка даёт
Download → Play/Open; новый релиз заменяет запуск на **Update**, активная задача —
на View progress. Установка продолжает использовать общий проверяющий helper,
очередь Downloads, атомарную активацию и сохранение данных/старых объектов.

**Start → Settings → Installed software → Automatic Crates updates** — сохраняемый
переключатель, исходно Off. После включения проверка сразу и раз в 15 минут,
после перезапуска через 30 секунд. Фоновый результат не открывает окно Downloads.
Автоматика работает только с установленными пакетами и `supported` для текущей
архитектуры; игровая сессия удерживает установку. Отключение снимает ожидающие
автозадания; повторное включение разрешает поставить их снова. Явная отмена,
пауза и ошибка требуют ручного действия для той же версии и переживают restart.
Более новая локальная числовая версия не откатывается до старой в каталоге.

Добавлен явный `checked` у строки настройки: положение переключателя соответствует
состоянию, независимо от Reduced motion. Обнаруженная отсутствующая регистрация
готового изображения Golf исправлена в CMake, без замены самого изображения.

## Проверки

ARM64, Fedora 44 / Qt 6.11.2 / GCC 16.2.1, отдельный builder на Odin без сети.
Сборка использует текущие совмещённые исходники оболочки, включая параллельные
изменения multiplayer. Исходники Crates в Git и фактическая сборка с наложением
остальных потоков — разные идентичности.

- CratesTests: **23 passed**, включая обновление через основную кнопку, возврат
  Play после активации, фоновую проверку без открытия Crates, сохранение настройки,
  deduplication, отмену/паузу/ошибку после restart, offline, совместимость,
  отозванный пакет, более новую локальную версию и защиту текущей сессии.
- Визуальные кадры используют отдельные fixture-пакеты и временные настройки,
  без подмены реальных установок: [Update](update-primary.png),
  [очередь ждёт игру](update-queued.png), [Off](automatic-updates-off.png),
  [On](automatic-updates-on.png). Это ARM64 offscreen + виртуальный SDL/программный
  ввод, не физическая приёмка кнопок или настоящего касания.
- Дополнительно запущенные CoreTests дали **5 passed / 2 failed**:
  `navigationAndBack`, `emptyAndMissingData`. Оба теста падают и на прежнем бинарнике
  в исходном builder (первый на другой проверке навигации). Они относятся к старому
  сценарию общего меню; общий набор не объявлен успешным и здесь не переписан.

Проверки обновлений не требуют нового публичного релиза или понижения установленных
игр. Каталог/игры не публиковались; серверная приёмка Golf остаётся остановленной
по новому указанию владельца. Общий updater TrainerOS/Armada — отдельная функция.
