# Patreon: сервер, профиль и поставка — 29 октября 2026

## Изменение и принятые условия

Spark / Искра: **$3/месяц, ×2 Искр**. Supernova / Сверхновая:
**$5/месяц, ×3 Искр**. Оба уровня созданы на странице AbyssTail.
Опыт не умножается; разовой ежемесячной выдачи валюты нет. Свежая проверка
членства запускает прежний механизм недостающей доплаты по каждой награде.
Отмена/отключение не отбирают Искры или покупки.

[Контракт](../../../services/backend/support-binding.md) описывает серверные
границы, обновление токенов, срок подтверждения и восстановление.
В оболочке: профиль → поддержка → управляемый браузер → тот же профиль.
Доступны проверка членства, страница Patreon и подтверждаемое отключение.
Прежний вход TrainerOS/Fluxer сохраняется.

## Сервер

- Развёрнута schema 0013 с резервной копией перед миграцией. API и worker работают
  с отдельной закрытой конфигурацией Patreon; ключи/токены не входят в Git.
- **141 тест** на изолированном PostgreSQL: привязка к владельцу и исходной
  сессии, одноразовый возврат, поздние ответы, конфликт идентичности, шифрование,
  отзыв/истечение подтверждения, обновление токенов, webhook и сохранность покупок.
- Проверка API с контролируемым ответом провайдера: 750 → 1750 при ×2,
  повторная проверка сохраняет 1750, переход ×3 даёт 2750; отмена сохраняет 2750,
  2000 XP и купленное оформление. Это тестовые данные, не живая выплата.
- Настоящий Patreon прислал тестовый webhook на публичный endpoint с HTTP 200.
  После неисправного Resume в portal зарегистрирован webhook официальным API:
  шесть member/pledge triggers, `paused=false`, ошибок 0. Старый portal webhook
  удалён. Подпись окончательного webhook проверена на работающем Backend.
- Неавторизованный просмотр поддержки и неподписанный webhook отклоняются.

## Установленные устройства

Одинаковая итоговая сборка запущена на **Odin и Flip**. На обеих — pack 10.
Flip сохранил уже установленный пакет; Odin получил пакет из `f1b9df86` после
штатного окончания Micro Rally. На обеих устройствах проверены hash живого
процесса, неизменность настроек и четырёх защищённых таблиц, `quick_check=ok`.
Резервные копии оставлены. Odin: громкость 0%; Flip: прежние 20%.

На Odin первая попытка откатилась из-за громкости 10% вместо требуемых 0%.
После повторных быстрых остановок supervisor вывел сессию в рабочий стол Armada.
Доставка завершена через штатное восстановление графической сессии, без reboot;
проверены Home, профиль, поддержка и живой `avatar.resolve` с pack 10.
Отсутствие пересечений глаз и геометрия переиспользуют описанные выше проверки;
новой игровой/Godot-приёмкой это не считается.

Изолированный UI-сценарий завершён без diagnostics/QML warnings; компактный
экран просмотрен. Широкий снимок тестового окна обрезался из-за управления
размером со стороны Gamescope и не использован как визуальное доказательство.
Полный экран поддержки проверен в обычной установленной оболочке: светлый на
Odin, тёмный на Flip; отступы, две колонки и панель действий видны целиком.

На Flip реальная кнопка Connect открыла страницу входа Patreon. Закрытие
созданного браузерного окна вернуло в тот же профиль; Cancel connection отменил
попытку, сохранив TrainerOS/Fluxer-вход. Подтверждение OAuth и доплата проверены
автоматическими сценариями, но **не реальным оплаченным аккаунтом**.

См. [сводку установки](delivery.json), [компактный экран с тестовыми данными](support-compact.png).

## Оставшиеся условия

Реальная оплаченная подписка, продление/отмена, живая доплата и перенос привязки
между аккаунтами не проверены/не реализованы соответственно. Личный Patreon
владельца не связывается с тестовыми Ren/Mika автоматически. Ko-fi не подключён.
Публичные описания тарифов сохраняют оговорку, что автоматические бонусы готовятся.
Физические кнопки и полный игровой прогон новой сборки остаются отдельной приёмкой.
