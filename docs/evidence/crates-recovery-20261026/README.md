# Crates: восстановление и переустановка — 26 октября 2026

Владелец согласовал следующий блок после прямой корзины: восстановление
прерванной установки и удаление/повторная установка с сохранением данных.
Владение остаётся у S13: Python Store/worker и CratesInstaller; потребители —
общие Downloads, Apps и CratesLibrary/S02. Новый сервис или менеджер не добавлен.

## Что изменилось

- Журнал операции записывается до изменения кода. Файлы, права выполнения,
  каталоги распаковки и публикация объекта сбрасываются на диск до receipt.
- Receipt — точка фиксации установки/удаления. До неё восстановление оставляет
  прежнюю версию; после неё завершает ярлык и очистку. Ярлык приложения больше
  не появляется раньше фиксации новой версии.
- При старте оболочки прежний worker восстанавливает журнал без сети/каталога.
  Блокировка запущенного приложения действует и при восстановлении. Повторное
  восстановление безопасно; данные владельцев не входят в очистку.
- Downloads сверяет прерванную операцию с установленной версией и SHA-256,
  сохраняет очередь и паузы. Retry работает и для удаления, у которого receipt
  уже отсутствует. На время восстановления нет ложной кнопки отмены фиксации.
- Повторная установка возвращает прежний `crates:<id>` в библиотеку без дубля.

- [SDK launcher](launch-tests.log): **2 passed**. Сохранены обнаружение SDK,

- Установленный `/var/opt/traineros/crates/installer.py` на
  [Odin](odin-installed-helper-tests.log) и [Flip](flip-installed-helper-tests.log):

Все аварийные сценарии использовали временные HOME/store и тестовые архивы.
Пользовательские игры не удалялись и не запускались ради этой проверки.

## Границы доказательств

Это проверка аварийного завершения процесса, не отключение питания/сброс устройства.
Qt-тест библиотеки и проверки установленного helper не заменяют полный физический
маршрут игрока с произвольным внешним пакетом. Совместимость таких пакетов,
физический ввод и фактическое обновление следующего опубликованного релиза остаются
открыты. Автоматический откат уже запущенного неисправного приложения не добавлен.
Ранее зафиксированные два падения общих CoreTests не относятся к этой правке
и не выдаются за исправленные. GitHub не публиковался; Backend/Golf не возобновлялся.
