# CRATES-74 — главная витрина

18 октября владелец принял три визуальных концепта Crates и разрешил начать
поэкранную реализацию с главной витрины. Уровень: 3/6, Высокое.
Актуальные требования: #144–152, #224/#227; общий CRATES-16 остаётся открытым.

## Этот этап

- [x] Два крупных ящика What's New / Workshop, четыре тематических ниже.
- [x] Отдельные иллюстрации; корпус, крышки, защёлки и выделение средствами QML.
- [x] Существующие рамка, вкладки, масштаб и глобальные X/Y сохраняются.
- [x] Джой/касание, открытие с короткой пропускаемой анимацией, B назад.
- [x] Reduced Motion; отмена незавершённого открытия при уходе с экрана.
- [x] Ручное описание ящиков в data/crates/showcase.json, устойчивые ID.
- [x] Сборка, проверка переходов, реальные снимки и доставка на Odin/Flip.

На этом этапе ящики пусты: вымышленные игры/рейтинги из концептов не становятся
данными продукта. Открытие показывает оформленное пустое состояние и возврат.
Top Rated/Update All появятся с их рабочими источниками; ложных кнопок нет.
Главная не обращается к сети, не запускает игры, не устанавливает пакеты.
