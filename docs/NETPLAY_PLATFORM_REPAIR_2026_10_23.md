# NetPlay: общий транспорт и проверка семейств — 23 октября 2026

Продолжение [первого исправления PS1/Wi-Fi](NETPLAY_STABILITY_2026_10_23.md)
по поручению владельца исправлять найденное и проверить остальные совместимые
платформы. Remote Play как пользовательская функция остаётся вне этого прохода;
постоянная доставка Iris ведётся отдельно. Владелец разрешил подключения,
изменения и проверки Flip/Odin. Запрет sleep/lid/suspend сохраняется.
Рабочая ветка `codex/netplay-stability`, владельцы S03/S07, потребители S06/S08,
сквозной путь F04. Чужие Apps/SDK/avatar изменения не затронуты.

## Исправленные механизмы

### Очередь общего моста RetroArch

`NetplayClient` считывал весь доступный блок и разрывал соединение, если вместе
с ещё не отправленными данными он превышал 8 МиБ. Медленный получатель или большой
пакет состояния ошибочно становились фатальным отказом. Теперь чтение ограничено
свободным местом выходной очереди и возобновляется по `bytesWritten`.
Лимит памяти и проверка пароля сохранены; действует обычное TCP backpressure.
Это общий маршрут Online RetroArch и наблюдения Hotseat, без нового протокола.
Прямое Nearby соединение без этого моста не затрагивается.

На ARM64 старый код провалил оба теста с передачей 32 МиБ и временно остановленным
получателем. Исправленный код доставил весь поток в обоих направлениях, затем
следующее сообщение по тому же соединению. Все **14 тестов моста прошли**,
включая фрагментацию, пароль, остановку/новую сессию из callback и Hotseat.
Это воспроизведённый дефект транспорта; его наличие само по себе не доказывает,
что именно он вызвал каждый сообщённый владельцем игровой фриз.

### Связанные GB/GBA и задержка ввода

SameBoy с двумя машинами и mGBA splitscreen с 2–4 машинами используют RetroArch
rollback. Первое условие адаптации 0–6 ошибочно исключало их по признаку работы
с батарейным сохранением. Условие теперь проверяет транспорт: netpacket исключён,
rollback получает native LATENCY bounds. Возврат SRAM, RTC, владение сохранением
и временные файлы не изменены. Отдельный PS2 candidate не допускается этим изменением.

### Кэш рендерера при новом приглашении

Приватные профили Dolphin, Azahar и RMG удаляли кэш вместе с временной сессией.
Добавлен общий `NetplayCache.h`: отдельный каталог в стандартном cache location,
разделённый по семейству и хэшу runtime. Dolphin связывает только `Cache/Shaders`,
Azahar — `shaders`, RMG — XDG cache в обоих Nearby/Online вариантах.
Конфигурация, карты памяти и firmware не переносятся в кэш. Старые пользовательские
каталоги не импортируются. При недоступности постоянного кэша сохраняется прежний
временный каталог; кэш не становится обязательным условием запуска.

Регрессия проверяет два последовательных запуска: кэш переживает завершение,
временная карта удаляется, новая сборка runtime получает отдельный каталог,
обычный конфиг остаётся прежним. На исходном коде тест воспроизвёл потерю кэша.
Это устраняет повторный холодный старт; первая компиляция ранее не виденных
шейдеров и недостаточная производительность устройства остаются отдельными причинами пауз.

## Проверенные семейства и границы

| Семейство | Что проверено / изменено |
| --- | --- |
| NES/FDS — FCEUmm, профиль Nestopia | Общий rollback, приватные options, firmware/контроллеры; исправление моста. Nestopia отсутствует на обеих портативках, новая установка не выполнялась. |
| SNES — Snes9x | Общий rollback, Multitap/раздельные места; исправление моста. |
| SG-1000/Master System/Mega Drive/Sega CD/32X — Genesis Plus GX/PicoDrive | Общий rollback, независимый firmware fingerprint; исправление моста. |
| PC Engine/CD/SuperGrafx | Общий rollback, private Multitap; исправление моста. |
| Atari 2600 — Stella | Общий rollback; исправление моста, без выдуманных core options. |
| PS1 — PCSX ReARMed | Сохранено установленное исправление GPU option/v2; добавлено исправление моста. |
| Neo Geo/arcade — FBNeo/MAME | Общий rollback; исправление моста. Разные ROM sets/CHD и тяжёлые автоматы не становятся автоматически совместимыми. |
| GB/GBC/GBA | Проверены netpacket и linked rollback отдельно; исправлены bounds для SameBoy/mGBA. |
| N64 — RMG | Native networking и очередь с credits сохранены; XDG cache теперь переживает Nearby/Online сессию. |
| GameCube/Wii — Dolphin | Native NetPlay/пять кадров upstream buffer сохранены; исправлено хранение shader cache. Фиксированный buffer не гарантирует плавность при любом RTT. |
| Dreamcast — Flycast Dojo | GGPO и private VMU/flash проверены по исходникам; delay 0 совпадает с upstream default и сам по себе не признан дефектом. Установлен OpenGL; произвольная смена renderer/задержки не выполнялась. |
| PSP — PPSSPP | Собственная Ad Hoc сеть; сохранены отдельная Lumines clock policy, запрет savestate/speed change и личный MAC/save lifecycle. |
| DS — melonDS | Собственный deterministic multiplayer, bounded transport/credits и проверенный возврат личного save; shared-console настройки не переносятся сюда. |
| 3DS — Azahar | Native room/личный NAND/SDMC сохранены; исправлено хранение shader cache. |
| Vita — exact vitaQuake | Собственная LAN сеть и личный runtime; transport admission/cleanup проверены, коммерческий AdHoc/PSN не заявлен. |

Все 15 проверенных установленных RetroArch core-файлов совпали между Flip/Odin
по SHA256. Манифесты standalone на обоих указывают одинаковые закреплённые
upstream revisions. Это проверка установленного состава, не новый игровой матч
по каждой строке. PS2 candidate, Wii U с собственными console/account данными,
PS3/Switch и отсутствующие сетевые режимы этим проходом не объявляются рабочими.

Исправлены две ссылки registry на удалённый `MULTIPLAYER_PREPARATION.md`,
обновлены переносимые исходники и их SHA256, включая накопившееся отставание
экспорта от существующего кода. `check-adapter-knowledge.py` проходит:
3 exact profiles, 32 semantic и 170 runtime файлов. Статусы совместимости не повышены.

## Источники и повторная проверка

### Установленная сборка и проверки

На Flip/Odin установлен и перезапущен один бинарник:
`8778ea692105acb0e1ff89732d33bd1456cda0f111d6853a31a249b8577fb5a5`.
Сохранён предыдущий `d52144f9…`, зависимости проверены из каталога установки.
У обоих запущенных процессов подтверждён новый SHA256, 0 найденных QML errors,
Wi-Fi power save off и системная громкость 0.

ARM64: RetroArch **60/60**, socket bridge **14/14**, standalone **35/35**,
Flycast **4/4**, RMG **7 passed / 2 skipped**. Два RMG внешних server/TLS fixture
не настроены для этого прогона; старые доказательства не выданы за свежий запуск.
Python admission/lifecycle: secure channel **5**, Azahar **5**, Vita **7** — прошли.

Реальный Dolphin дважды запускался на каждом устройстве с production подготовкой
приватного каталога. Только для проверки кэша он запускался как solo:
6 shader-cache файлов сохранились между запусками, Flip **403 993 B**,
Odin **406 025 B**; второй запуск получил прежний каталог, ошибок runtime в логе
не найдено. Временные профили удалены, принадлежащие проверке процессы остановлены.
Это проверка native cache persistence; новый парный матч GameCube не заявлен.
Начальная попытка парного стенда не дошла до запуска: параллельная сборка/загрузка
образа на SD задержала fingerprint ROM Odin за пределы ожидания диагностического
скрипта. Таймаут этого стенда не признан дефектом обычного Lobby или Dolphin.

Для отката оболочки закрыть игры, восстановить сохранённый бинарник из приватного
каталога доставки и перезапустить TrainerOS. Кэши можно удалить отдельно из
`$XDG_CACHE_HOME/TrainerOS/netplay` (обычно `~/.cache/TrainerOS/netplay`): они
создаются заново и не содержат возвращаемые сохранения/карты памяти.
