# QUICK-30 — нижняя панель и группы приложений

16 октября 2026. Уточнение владельца к [QUICK-28/29](QUICK28_SHARED_DRAWER.md).
Поздние решения чата заменяют старую вертикальную геометрию #226; сам issue
не закрывается. Полный drag/reorder из #226 и другие экраны сюда не входят.

## Принятое поведение

- Раскрытый X продолжает нижний корпус во всю ширину. Верхние диагональные
  срезы убраны; внутренний скос соединяется с боками. Цвета и вложенные ширины
  повторяют существующую рамку ChassisFrame и текущую тему.
- Нет отдельной верхней полоски, заголовка, подложек или подписей приложений.
  Иконки центрируются; сложенные ушки, раскрытие и Recent games/Y сохранены.
- Слева неподвижные избранные, затем разделитель, справа запущенные вне
  избранного. Один значок на приложение; запущенное избранное остаётся слева
  с индикатором. Прокручивается только правая группа при переполнении.
- Лимит избранного рассчитывается из доступной ширины/масштаба. Зарезервированы
  два места для запущенных: это объявленное рабочее допущение, не отдельный
  подтверждённый владельцем выбор. Новые избранные сверх лимита не добавляются;
  меню объясняет необходимость убрать одно.
- Ранее сохранённые избранные сверх лимита не удаляются, остаются в Apps;
  панель показывает помещающуюся часть. Запуск такого старого избранного
  не переносит его в группу «вне избранного». При увеличении ширины вернётся.
- При изменении состава выбранное приложение удерживается по ID; при закрытии
  выбранного фокус переходит к ближайшей доступной позиции. Пользовательские
  списки и жизненный цикл окон не заменяются тестовыми данными.
