## Главная задача

Переделать поведение и убрать перегруз. Не превращать проход в добавление
всех функций Fluxer или косметическое переименование старых списков.

- Messages — люди: друзья и знакомые, включая друзей без переписки, разрешённые
  личные разговоры и запросы. Нажатие человека открывает его личку справа.
  Один человек сохраняет один диалог при смене дружбы и места входа.
- Communities — группы и комьюнити. Вход в комьюнити заменяет левый список
  его каналами и кнопкой назад к списку групп/комьюнити; не раскрывает дерево
  внутри общего списка. Разговор остаётся справа. У группы один разговор.
- Основные действия доступны непосредственно в разговоре. Редкое управление
  относится к информации о человеке/группе/комьюнити, не к общему меню чата.
- Всё сверх базового убрать с повседневной поверхности или скрыть в точном
  контексте. Не переносить прежнюю перегруженную простыню в пункт «Ещё».

## Разбор отклонённых меню

| Сейчас на снимках | Решение |
| --- | --- |
| Create lobby / Browse lobbies | Убрать из Social-меню; входы остаются Lobby/Home по последнему решению владельца |
| Play with group / Who can join my games / Join game | Убрать старое управление игровыми партиями из Social |
| Messages… / Communities… | Убрать дубли навигации из контекстного меню |
| Message tools… | Убрать из меню разговора; ввод и вложения доступны в строке ввода, действия над конкретным сообщением — рядом с ним |
| Members / Add friend / Rename group / Remove member / Invite link | Сведения и разрешённое управление соответствующей группой/комьюнити, не набор пунктов в каждой беседе |
| Mute conversation | Оставить базовое управление уведомлениями данного разговора |
| Leave group | Оставить в информации о группе с подтверждением, не смешивать с написанием сообщений |
| Refresh / My profile / Communication settings | Убрать дубли из меню списка: существующий профиль и системные настройки уже имеют свои входы |

Целевое короткое меню разговора: закрепление и уведомления. Профиль/информация
открывается через имя/аватар. Запрос дружбы получает подходящие ему действия;
блокировка и другие доступные меры безопасности сохраняются в карточке человека.
Доступ с геймпада должен быть равноправным: исчезновение Message tools не должно
сделать вложения или запись голосового доступными только пальцем.

## Сохраняем основу

Переписки, историю, черновики, непрочитанное, разрешения Fluxer, повтор отправки,
обычные вложения и голос не переписывать. Общие файлы/Downloads переиспользовать.
Сокращение медиа Lobby не распространяется на Social. Позднее уточнение владельца
о минимальных меню важнее перечисления прежних игровых действий в #217/#218.

Три раздела L2/R2: Messages / Communities / Discover. Возврат восстанавливает
точное место, человека/канал, прокрутку и черновик. X/Y — глобальные панели,
внутри клавиатуры действует её управление. Тёплый компактный стиль TrainerOS,
круглые аватары, точка реального статуса, лёгкое выделение и разделители.
