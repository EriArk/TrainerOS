## Реализация

Один ContinueDrawer показывает два источника. Корпус ChassisDrawer не менялся:
высота 162, четыре карточки, прежнее раскрытие снизу вверх. Переключатель
прозрачный, без новой плашки; пустой список — звезда и спокойная подпись.
Уменьшена только внутренняя высота карточек и уточнены их отступы.

`GameFavorite` разделяет существующий предикат с GameCollections. Источник —
метаданные `favorite`, которые уже читает импорт gamelist; нового хранилища
или редактора отметок нет. Показываются зарегистрированные игры всей библиотеки,
без фильтра текущей коллекцией/платформой. Удалённые регистрации исключаются;
отсутствующий файл оставляет карточку с сообщением Game file unavailable.

Навигация сохраняется в существующем состоянии Trainer: источник, устойчивый ID
выбора и отдельные позиции прокрутки. Новый профиль/неизвестная версия навигации
сбрасывают эти поля. Старое состояние без позиции прокрутки сначала раскрывает
выбранную карточку. Изменение метаданных не заменяет потерянный выбор соседним;
подтверждение повторно проверяет существование регистрации и отметку favorite.

История запусков, обычные сохранения и контекст действующей игры используют
прежние механизмы. Выбор меняет игру Home без запуска. Настройки отображения,
автоматические коллекции и общий пересмотр физических обозначений #192 остаются
в своей очереди.
