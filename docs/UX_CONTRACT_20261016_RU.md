# TrainerOS: действующий контракт интерфейса и жизненного цикла

**QUICK-25 — окончательная форма X:** цельная панель корпуса с объёмными
кнопками в углублениях, без иконок, стоящих над полкой. По центру снизу,
ширина по содержимому; растёт высотой от фиксированной нижней рамки,
как ушки, а не выезжает/висит над ней. Это заменяет полку QUICK-24.
Порядок/перекрытие ушек и исправленное положение Y сохранены.

**QUICK-24 — окончательное уточнение владельца:** ушки слева; Quick Apps
поверх жёлтого Recent games справа, наложение 32 вместо 8 без лишних скатов.
Quick Apps раскрывается как док старого Mac OS по центру снизу: перспективная
площадка с настоящими иконками, ширина по содержимому с ограничением экрана.
Берём концепцию, не копию: док вырастает из корпуса и использует его материал;
стекло и зеркальное отражение исключены. Проверять с настоящими избранными Apps.
Y сохраняет прежнюю панель. Это заменяет геометрию QUICK-23 и промежуточный
вариант QUICK-24 с жёлтым сверху. По дополнительной коррекции аккуратности
ушки чуть шире (174 × 36), Y и подпись сдвинуты внутрь, посадка прежняя.
Установлено на Odin/Flip; [проверки и границы](QUICK24_OVERLAP.md).
Далее — просмотр владельцем, новый экран пока не начинаем.

**Объём интерфейса — решение владельца:** форма литого пластика, толщина граней,
мягкие контактные тени и блики сверху; единый свет и палитра TrainerOS. Текст и
игровые данные остаются читаемыми. Применять поэкранно, без общей переделки за раз.

**QUICK-23 — уточнение владельца:** оба ушка рядом слева, примерно на треть
меньше QUICK-22 (162 × 36 вместо 242 × 53), округлые скосы и круглые Y/X.
Сохраняем посадку на нижней окантовке экрана, без отдельной накладной полосы.
Y жёлтое, X в цвете темы с розовой клавишей; размеры открытых панелей прежние.
Это заменяет размещение справа и зеркальное ушко из QUICK-22; поведение прежнее.
Установлено на Odin/Flip; [проверки и границы](QUICK23_LEFT_HANDLES.md).
Следующий шаг — просмотр владельцем, другие экраны пока не начинаем.

**QUICK-22 — решение владельца:** Quick Apps X становится горизонтально
отражённой правой парой Adventures Y: общая форма корпуса, анимация и логика,
меньшая раскрытая высота под иконки приложений. Оба закрытых ушка короче и
одинаковой ширины. Вертикальный док и сужение экрана заменяются этим решением.

## Как читать и применять

Перед блоком перечитать его раздел плана и живые issues целиком, включая последние
уточнения. Позднее явное решение заменяет конфликтующее раннее; заголовок или
старый checkbox не отменяет новое дополнение. При неразрешённом противоречии или
существенной развилке спросить владельца до зависимой реализации. Технические
гипотезы проверять, не превращая их в обещания. Сохранять общий стиль и логику
TrainerOS, использовать существующие службы и компоненты.

Слова «требуется», «цель» и таблицы ниже не означают готовность. Исторические
документы сохраняют доказательства прежних сборок, но их старые «следующий шаг»
не управляют очередью. README и снимки не обновляются под ещё не поставленный UI.

## 2. Общий стиль, вывод и управление (#77, #156–160, #192–193, #224–234)

Сохраняются корпус/скат, тёплые цвета, материальные кнопки, золотой фокус и
компактность TrainerOS. Light/Dark — два читаемых варианта этого же языка, не
новый магазин тем. Не заменять интерфейс стандартными desktop-виджетами или
чужим оформлением. Проверять композицию, реальные иконки, пропорции и возврат
на устройствах; до их доступности явно отделять host-render от установленного UI.

Геометрия зависит от реальных доступных границ окна/вывода, DPI и safe area,
а не обязательной композиции 960×540, растянутой целиком. Логические единицы,
физические пиксели и разрешение арта различаются. Auto/Handheld/TV определяют
дистанцию просмотра отдельно от разрешения; 4K не означает мелкие контролы.
Общий размер интерфейса настраивается на лету: шрифты, кнопки, рамка и popup
масштабируются согласованно. Qt DPR применяется один раз; размер окна остаётся
адаптивным. Настройка доступна и после увеличения размера.
Последнее уточнение HOME-19: спокойная заглушка с небом, солнцем и дорожкой
имеет свою согласованную палитру для каждой темы. Она покрывает только игровую
карточку Home. Полупрозрачный скриншот на Home пока отключён; захват и история
не удаляются. Снаружи сохраняется обычная бумага/корпус TrainerOS.

| Действие | Общий контракт |
| --- | --- |
| D-pad / левый stick | Пространственный фокус; A действует на видимую выбранную цель |
| B | Закрыть верхний допустимый слой/назад с восстановлением фокуса |
| X / Y | Quick Apps / Recent+Favorites на всех глубинах оболочки |
| Select | Контекст захваченного объекта; Browser/Files — переключение toolbar |
| Home | В оболочке Shell Options; в игре Game Options |
| Start | Dashboard в оболочке; настоящий игровой Start остаётся игре |
| Правый stick | Общая прокрутка только у активной поддерживающей поверхности |

Клавиатура и защищённые модальные окна имеют приоритет над X/Y. Игра и внешнее
полноэкранное приложение владеют своим вводом до явного возврата. Не назначать
освободившиеся действия на L3/R3 без аудита. #77 сохраняет автоматическое
распознавание физического контроллера и корректные glyphs/семантику, ручную
настройку, безопасный неизвестный профиль и полное управление касанием.

Общий менеджер временных popup закрывает X/Y/context/folder при реальной потере
фокуса; дочерняя клавиатура не считается потерей. Внешний безопасный tap может
одновременно закрыть popup и один раз активировать цель. Защищённый consent,
пароль, сохранение/удаление не отменяются и не подтверждаются сквозным нажатием.
Каждый слой владеет вводом с neutral/release barrier; события не протекают в игру.

Browser/Files: левый stick — указатель, правый — scroll, D-pad — focus, короткий
A — click, удержание A — настоящий context, B сначала закрывает popup, затем
идёт по истории. Показ панели не останавливает фоновые операции.

## 3. Home, Options и игра (#167–173, #188–196)

Home: справа примерно две трети ширины — высокий display-only showcase адаптера
и единственная меньшая кнопка Play/Resume/Return, принадлежащая оболочке. Слева
сверху — непрочитанная/необработанная активность с полосой 5–6 аватаров чатов;
слева снизу — настоящие недавние RA всей библиотеки. Pokémon badges и transient
toast не подменяют эту зону. Исходный фокус Play; после навигации A действует
на выбранный чат/уведомление/достижение. Новое событие не крадёт фокус;
прокрутка не помечает прочитанным, просмотр приглашения/звонка не принимает его.

Уточнение владельца по визуальному результату: даже первый запуск без друзей,
игр и наград должен быть красочным и оформленным. Сохранить объёмную круглую A,
значки/медальоны достижений и иллюстрированное пустое состояние без выдуманных
контактов или разблокировок. Последнее уточнение заменяет прежний фон-скриншот:
тематическая заглушка остаётся фоном, а сохранённый кадр показывается отдельно
в коллаже наклонённых рамок снизу карточки. Коллаж открывает GameHub → Overview →
Screens; это действие оболочки, не адаптера. Отдельная надпись Start Adventure
убрана; Start/Resume/Return печатается внутри круглой A. Без снимков — оформленные
пустые рамки, без выдуманных кадров. Полная галерея остаётся #203.
IMG_1045 задаёт визуальный язык, не возврат к старой навигации.

Успешный запуск обновляет контекст и хронологию. Hover, подготовка и выбор Y
не создают игровую сессию. Y выбирает Home-игру без запуска; настоящая активная
игра фиксирует контекст, пока процесс жив. Exit возвращает предзапусковой маршрут
и фокус, сохраняя последнюю игранную игру. Сейвы/точная идентичность не меняются.

Shell Options — тёплая почти полноэкранная панель (85–95%): слева реальная живая
активность либо компактный профиль, справа действия и inbox без дублирования.
Сообщение открывает точный полный Social и закрывает Options; B не создаёт его
снова. В правом верхнем углу только здесь Settings / Power / Switch launcher.
Выключение/смена режима открывает штатное подтверждение, не выполняется первым tap.

Game Options относится к реальной игре: арт слева, Continue/Minimize/Notifications/
QuickChat/Together/Exit справа. Together ведёт в единственное Lobby. Системных
трёх иконок здесь нет; поддержанные графические настройки переезжают в Start → Game.
Только явный Exit запускает существующий защищённый capture/save/exit цикл.

Solo Minimize действительно приостанавливает тот же процесс, если runtime умеет
безопасно; иначе ограничение честное. Multiplayer продолжает работать. Home/
Game Options сами по себе не пауза. QuickChat solo получает подтверждённую pause
lease до фактического возврата в игру; multiplayer не замораживает. Это специальное
правило #171/#195, не отменённое ранней общей фразой «уведомления без паузы».
Не использовать обычные product savestates или повторный запуск вместо паузы.
Временный кадр Minimize не подменяет авторитетный свежий кадр подтверждённого Exit.

QuickChat — маленький текстовый вход в существующий точный диалог, а не второй
мессенджер. Игровые сообщения: две строки на 3–4 секунды у подтверждённого аватара
автора; зрительские комментарии в отдельном углу, видны игрокам с opt-out. Без
дублирования общим toast и утечки личных сообщений в захват.
Клавиатура #185: RU/EN QWERTY, справа 123/😀, буквы остаются видимыми; Y независимо
меняет буквы/знаки. Grapheme-safe редактирование; не предлагать emoji для PIN/секретов.

## 4. Games, Overview, RA и адаптеры (#24–25, #48, #114, #197–207)

Корень Games: коллекции горизонтально сверху; ниже яркие карточки платформ в
две строки на handheld, три при наличии места. Нет отдельной All Games/Favorites
плитки; общий поиск по библиотеке сохраняется. Четыре вида: Wheel с прежними
логотипами и правой информацией; List с той же правой панелью; настоящие Shelves;
Grid во всю область без правой панели. A запускает напрямую.

Коллекции расширяют текущую службу: ограниченное дерево AND/OR/NOT по настоящим
метаданным, preview/count, явные include/exclude Adventure ID, миграция v1 и
разделение Trainer. Y — тот же нижний левый drawer Recent(default)/Favorites.

Overview содержит реальную Timeline и Screens. Единый индекс медиа связывает
owner/game/session/source, различает финальный Exit и достижение. RA — общая
галерея earned/locked/unknown, Standard/Hardcore, trophy art и подробности.
Живой unlock screenshot разрешён только при доказанном live exact-event:
сравнение baseline/return не доказывает момент. Без события остаётся запись RA
без выдуманного кадра. Звук вдохновлён Xbox360, но оригинальный, без копирования.

Experience API заменяет обязательные first/second slots одной optional Adapter
face: label/icon, стабильные menu IDs, capabilities, trusted presenter. Перенос
одних QML-файлов недостаточен: resolver/registration, mount/overlay, navigation,
callbacks, persistence и ограничения тоже меняются. Home showcase и безопасные
session/Select hooks остаются. Проверка — настоящий другой адаптер через тот же
публичный контракт без правок общей оболочки.

Pokémon: Field Guide / Party / Boxes / Care Center / Playroom / Shops / Trainer
Card / Journey / Hall of Fame в левом меню. RA и универсальный профиль здесь не
дублируются. Сложные операции могут временно расширять область, а не сжимать
существующий экран до непригодной половины. Experience UI не равен runtime
AdventureAdapter. Presentation/catalogue match никогда не разрешает semantic
save write; все exact-build, owner, backup/transaction guards сохраняются.

## 5. Social и Lobby (#127–135, #179–187, #208–223)

Messages — только 1:1: все друзья, включая без DM, входящие/исходящие запросы,
допущенные незнакомые; закрепление и один account/DM identity. Communities — группы
с прямым чатом и комьюнити с вложенными каналами. Категории — заголовки, создаются
text/voice каналы; просмотр voice не подключает. Вступившие комьюнити без тега
TrainerOS не исчезают. Discover — People/Communities, invitation preview и Recently
Together только реально совместно игравших, не зрителей или ожидающих комнаты.
Сохраняются временные социальные связи/очистка и возможность обычного добавления
в друзья через существующий координатор, с проверкой реальных разрешений Fluxer.

Использовать native Fluxer discovery/tagging, если доступен; не обещать автоматическое
попадание в каталог и не строить второй серверный registry. Один профиль, проверенный
presence-dot. Playing-game виден друзьям на уровне доставки данных, не только UI;
если провайдер этого не умеет, не публиковать публично. Исследовать безопасную
адресную доставку, не создавать скрытый спам обычными DM.

Один согласованный call живёт через навигацию/игры; переключение требует решения,
не открывает второй микрофон. DM preview по умолчанию включён и настраивается;
группы/каналы — badge кроме mentions/replies, без toast «друг начал играть».
Один event → одна индикация. Общие rich media для DM/групп/каналов/Lobby и Downloads,
без автоматического импорта ROM/сейвов. QuickChat остаётся text-only.

Lobby находится только в GameHub и существует без игры, сохраняет участников и чат
между играми. Все обычные NetPlay/RemotePlay/native LAN входы — deeplink в него,
включая игру, Home, Games, DM, группы и комьюнити. Adapter Link/trade/gift/practice
сохраняет собственные доказанные семантические маршруты и save guards.

| Тип комнаты | Соединение и доступ |
| --- | --- |
| Online | Fluxer signaling/объявления; Open / Approval / Private invite-only, без паролей/IP |
| Local | Реальная offline LAN, без Fluxer login, интернета или публичного каталога |

Тип неизменен после создания; смена требует новой комнаты. Online access можно
менять без изгнания допущенных. Local не копирует три Online режима, не получает
новый offline messenger/voice/stream стек. Общий room coordinator сохраняется,
identity/transport отделяются; Pokémon Bluetooth не объявляется общим netplay.

Комната: крупные аватары игроков и динамическая доказанная вместимость, отдельный
ряд зрителей, компактная игра, справа полноценный чат, снизу mute/deafen/invite/Ready.
Выбор игры использует Games; режимы только реально доступные, один — автоматически.
Голосование 1–4 кандидатов, хозяин подтверждает победителя/ничью. Poll API Fluxer
ещё требует проверки; ограниченное room vote не является новым messenger.
После выбора хозяина подготовка автоматическая. Ready только после валидной
готовности; все текущие игроки Ready → один запуск. Зритель не нажимает Ready.
Недостающий ROM — явный picker/import/revalidate, не сканирование чужой библиотеки
или автопередача. Remote Play гостю ROM не нужен. Активная игра закрывается только
по существующему сохранению/согласию; поздние действия старой комнаты отбрасываются.

Приглашение можно свернуть и развернуть; ручное закрытие своей игры его не удаляет.
Кнопка согласия проходит безопасное закрытие и затем подключение. Для уже работающей
нужной игры с настоящим встроенным online используется её совместимый путь.
Seat request: Accept/Later/Decline, резерв reconnect; late join только где доказан,
иначе следующий матч, без выдуманного распознавания игровых раундов.

Единая полупрозрачная перетаскиваемая touch-панель заменяет независимые кругляши
и corner edit mode. Self-mute общий, deafen локальный, per-person mute реально
отключает локальный track. Зрительский stream Fluxer — по согласию и спросу:
нет зрителей → нет capture/encode/uplink; несколько publishers, декодируется
выбранный поток. Комната видна даже без активного потока. Нужны реальные load checks.

Интерактивный Remote Play — отдельный прямой P2P путь; Fluxer помогает signaling,
STUN обнаруживает адреса, не пересылает видео. Тяжёлый сервер/VPS/TURN владельцу
не навязывать; сложный NAT отложен для беты. При совместной нагрузке предупреждение
один раз за сессию, необязательный spectator stream уступает игре.

#187 меняет строгий oldest-first на волну популярных NES/SNES/MD/PS1/PS2/GC/Wii
и стабильных NetPlay cores. Охват до Wii U плюс Vita остаётся; PS3/Switch исключены.
Обычного PSP достаточно, private parties и полный handoff-каталог отложены.
Под совместной игрой нужен couch с отдельными контроллерами, а не обязательная
передача одного. PS2 native online и couch — разные пути; не запускать две тяжёлые
копии на одной портативке. Переиспользовать рабочие механизмы и прошедшие проверки.

## 6. Apps, Crates и модули (#144–155, #224–232)

Apps: пять иконок с подписями в строке без подложек. Одноуровневые popup-папки,
touch hold/drag и Select-альтернативы; только первичная группа редких System/Utilities,
без последующей автопереклассификации. Поиск внутри папок; достоверно распознанные
Steam-игры по умолчанию исключены, клиент Steam остаётся. Это не ручное hidden.

Quick Apps — глобальный dock внизу справа, растёт вверх от нижней рамки, без прежних
верхних/нижних диагональных плеч. Складывается вниз до короткой ручки в цветах темы,
вертикально отражающей характер Y drawer, без обязательного жёлтого. Сохраняются
квадратные материальные кнопки, pin/running разделены углублением. Одна app-кнопка
для нескольких окон: последнее активное плюс picker. Pin order принадлежит Trainer.

Обычные приложения используют apps-service/GIO и владение Xwayland sessions;
close — штатный запрос с диалогом несохранённых данных, не kill. Без тяжёлого WM.
AP01 уже имеет каталог и проверенный оконный цикл, но Gamescope overlay не принят:
его фактическую видимость надо исправить. Native Wayland без управления не маскировать.
Фоновые приложения живут при переходе по оболочке и запуске игры.

Files: выбрать существующую лёгкую основу после проверки ARM/лицензии/встраивания
(MauiKit/libfm-qt — кандидаты, не решение), оформить в TrainerOS. Не подменять
внешним Dolphin или переписыванием всех операций. Copy tasks/file picker/Downloads общие.
Browser: встроенное современное ядро, сравнить QtWebEngine/WPE на реальном ARM;
Google services не включать. Компактная адресная строка, счётчик вкладок/thumbnail
popup, скрываемый toolbar вместо desktop strip; per-Trainer cookies/history/bookmarks,
живущие вкладки. Общие Downloads, в том числе authenticated/blob где поддержано.
Segmentation автоматически только при настоящих Range/206 и стабильном валидаторе,
с безопасным fallback; не обещать ускорение любого сервера.

Crates — утверждённое имя вместо OddCrate. Витрина физических ящиков, вручную
управляемый каталог владельца: крупные What's New без срока истечения и Workshop
для public experimental beta/stable, прочие ящики обычные. Top Rated — действие,
карточка проекта открывается popup здесь же. Каталог/delta только при открытии,
offline cache; бинарники GitHub Releases, без владельческого binary mirror и
постоянного опроса каждого проекта с устройства. Download/Update/Update All/old
version явные; одна установленная версия, shared Downloads, reserve/verify/install,
ожидание выхода активного приложения, безопасный rollback с сохранением данных.

Обычные Linux apps остаются Bazaar/host-managed. После ручного одобрения проекта
новый релиз не требует повторного одобрения каждого выпуска; права сохраняются.
Compatibility видна, explicit install anyway не обходит подписи/безопасность.
Crates reviews: установлен сейчас или раньше, звёзды/необязательный текст,
один user/project через версии, только допустимые модель/arch/tested-version.
Старые требования 2 часа/завершение сохраняются для обычных не-Crates reviews.
Donate — QR/браузер на одобренный creator URL, не собственные платежи.

System modules #231: versioned capability-limited SPI, владение ресурсами/session,
ограниченные subviews/actions/Settings/Start widgets; без новых primaries и raw
untrusted QML. Это не Experience adapter #207 и не packaged adapter #92; общие
trust/install primitives переиспользуются. Installed = available, пользователь
удаляет ненужное, обычного enable-toggle нет. Host quarantine — восстановление.
Trusted local dev install допустим. Start widgets теперь приняты #233, не deferred.

## 7. Start, Settings, ScreenScraper (#26, #29, #35–39, #65, #71, #233–234)

Start: QuickActions / Extensions по L2/R2, страницы внутри по L1/R1, default
QuickActions. Просторная общая сетка; Device первым, Game ниже только для реальной
живой сессии через Home → Game Options → Start. В этом пути Start/B возвращает
Game Options, Home закрывает оба слоя и возвращает ту же игру. Игровой Start не перехватывать.
Volume/brightness/radios/Downloads/one-press scraper; настройки графики только
реально поддержанные, per Trainer + exact game, с различением live/next-launch.

Обе поверхности редактируются Edit/+: snap/resize/hide/restore, touch drag и
именно здесь controller A pick/place, B cancel. Один instance каждого widget type,
несколько разных типов/размеров от extension; pinned functions в QuickActions,
без обычного enable-toggle. Пустые страницы убираются, новые добавляются; layout
per Trainer. Get Extensions → Crates. Скрытое UI не выполняет лишний refresh,
валидные фоновые задачи продолжаются. Политику auto-add новых widgets не выдумывать.

Settings открываются только через иконку Shell Options, сохраняют левую колонку
категорий и правое содержимое, смысловые IDs вместо 15 numeric categories:

| Раздел | Принадлежность и содержание |
| --- | --- |
| Personalization | Light/Dark, motion, UI audio, display/media, per Trainer |
| Device | Display/audio/controllers/connectivity/RGB/haptics по реальным возможностям |
| Accounts & Communication | Trainer/RA/Fluxer, voice, privacy/notifications, общие providers |
| Games & Library | Roots/storage/saves/media, полные настройки ScreenScraper |
| Installed Software | Apps / Extensions; Linux Manage → реальный host manager; Crates Remove → общий backend |
| System | Updates/date-time/diagnostics/about/credits, без дублирования Power/Launcher |

При удалении данные сохраняются по умолчанию; отдельный unchecked Delete app data
требует явного решения в разрешённой области. Built-ins только информация. Удаление
модуля убирает его widgets/pins, совместимая конфигурация сохраняется для reinstall.
Device hardware/inventory общие; личный UI/accounts/layout per Trainer; graphics
per Trainer + exact game. Нельзя утечь в соседний профиль при переключении.

Software и подготовленная OS имеют фоновую проверку наличия, но download/install
только вручную. Crates проверяется только при открытии. SteamOS/Bazzite обновляет
сам host; rollback только на реально доказанных механизмах. Не создавать новый
device backup wizard или watchdog многократных стартовых падений. #39 conditional
Steam install/restore не равен launcher switch и пока не подтверждён старым CLOSED.

ScreenScraper #65: Start запускает одной кнопкой missing-only по всей подходящей
установленной ROM-библиотеке без обязательного picker платформ и duplicate jobs.
Полные сгруппированные настройки остаются Games & Library: account/API/quota,
язык/регион, metadata/art/video, matching, existing-data, display. Валидность и
полнота используют выбранные поля, fingerprint/provenance; пользовательские
названия/арт и Crates не перезаписываются. Aggressive default с ранжированием и
confidence margin, Cautious по выбору; ambiguity → Downloads Needs attention,
очередь идёт дальше, коррекция конкретной игры сохраняется. Base-game art для
modified ROM помечается и не меняет exact identity/save authority.
Download videos ON по умолчанию; только действительные варианты/лимиты и локальная
Batocera-compatible media. Play previews и preview sound — отдельные display
настройки, звук по умолчанию выключен. Не обещать online auto-stream.
