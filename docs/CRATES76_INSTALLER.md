# CRATES-76 — действия проекта и установка

## Текущий UX обновлений — 26 октября 2026

По решению владельца выбор версий удалён из обычного интерфейса. Карточка
предлагает Download для нового пакета, **Update вместо Play/Open** при доступном
новом релизе и Play/Open после установки. Во время операции — View progress.
Архитектуру выбирает общий установщик. Исторические проверки Versions ниже
сохранены как доказательства старой реализации, а не как текущий UX.

В Start → Settings → Installed software добавлен **Automatic Crates updates**.
Настройка сохраняется на устройстве; исходно выключена. После включения проверка
идёт сразу, затем раз в 15 минут; при следующем запуске — через 30 секунд.
Не требуется открывать Crates. Автоматика обновляет только уже установленные
пакеты с совместимостью `supported`, через существующий подписанный каталог,
общую очередь Downloads и защиту текущего игрового сеанса. Отключение отменяет
ожидающие автоматические задания; уже выполняющаяся транзакция завершается штатно.

Пауза, отмена и ошибка не запускают повтор той же версии при каждой проверке
или перезапуске оболочки. Retry остаётся явным действием. Новая версия может
снова попасть в очередь. Отозванные/чужой архитектуры/непроверенные пакеты
автоматически не устанавливаются. Более новая локальная числовая версия не
понижается до старой из каталога; для нечисловых версий используется порядок
каталога, только если установленная версия в нём известна. Личные данные и
предыдущие объекты сохраняются прежним установщиком.

Проверки и доставка: [отчёт обновлений](evidence/crates-updates-20261026/README.md).

## Что не объявляется завершённым

- Физический геймпад и Home/минимизация с реальных кнопок, полноценный игровой
  сеанс и совместимость иных устройств требуют отдельной приёмки.
- Сейчас у каждого проекта одна опубликованная версия. Downgrade и защита
  занятого приложения проверены синтетическими архивами, не двумя публичными релизами.
- Сохраняется предыдущая версия при неуспешной замене; автоматического отката
  после неисправности уже запущенного приложения пока нет. Retry скачивает заново.
- Установка не обещает поддержку RA, обложек или всех ROM-функций для native-игр.
- Следующий блок: серверный delta-каталог #146, затем оставшиеся рецепты; отзывы,
  донаты и модули остаются в общем плане.

Локальные логи/снимки: `work/crates76/`. Прежняя витрина CRATES-75 не считается
доказательством установки. При первом выпуске предусмотрена только одна версия
каждого пакета; механизм downgrade проверяется отдельными тестовыми архивами.

## Актуальный учёт внешних установок — 24 октября 2026
<a id="live-inventory-20261024"></a>

CratesInstaller владеет учётом активных receipts; существующий PlatformBinding
передаёт `inventoryChanged` в SDK и список игр Lobby. Теперь directory watcher
замечает атомарную замену файлов в `active/` внешним штатным установщиком,
появление/пересоздание папки и удаление пакетов. События объединяются за 100 мс;
неизменный inventory не создаёт повторных уведомлений. Каталог релизов и сеть
для этого не запрашиваются, личные данные и установочные транзакции не меняются.

Причина инцидента: внешняя установка Golf 0.1.19 на Odin/Flip обновила файлы,
но работающий CratesInstaller перечитывал inventory только после собственного
worker или при configure. SDK удерживал прежний activity protocol и возвращал
`invalid_activity` для установленного `pocket-golf.6`. Отказ воспроизведён на обоих
реальных SDK через hello → activity.register, без запуска партии.

ARM64 CratesTests: 18 passed. Новая регрессия проходит первую внешнюю установку,
атомарное обновление протокола, независимую вторую игру, удаление и отсутствие
ложного изменения при записи постороннего файла. Проверки совместимости SDK
сохраняются; это исправление обновления учёта, а не разрешение смешанных версий.

Доставка: исходники `d1fd007`, ARM64 SHA256
`427155ed080ae6d74b3ec64b2dd3cc644fb582bfb2a0cdc9f66d215071faf2f4`.
Оболочка установлена на Odin/Flip; проверен хеш работающих процессов, прежний
бинарник сохранён для отката. Один перезапуск оболочки загрузил актуальный
inventory. Тот же hello → activity.register с `pocket-golf.6`, который до этого
возвращал `invalid_activity`, теперь успешен на обоих устройствах. Файлы игры,
эмуляторы, профили и настройки не заменялись. Полный повторный матч из Lobby
после исправления остаётся отдельной проверкой владельца; новая партия не запускалась.
