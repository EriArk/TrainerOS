# CRATES-76 — действия проекта и установка

Согласовано 18 октября: после изучения #145–148 владелец разрешил общий
установщик и первые два пакета — 2048 и FeatherPad. Рецепт подготовки отдельный
для каждого проекта; установка, очередь и владение файлами общие.

- [ ] Основная кнопка Download → Play/Open, реальный статус, Versions/Remove.
- [ ] Проверенный пакет → staging → атомарная активация; данные отдельно.
- [ ] Общие Downloads, отмена, повтор после ошибки, отсутствие дублей.
- [ ] Обновление/предыдущая версия, ожидание закрытия, восстановление после сбоя.
- [ ] Рецепты 2048 и FeatherPad, лицензии и фиксированные исходники.
- [ ] Игры через общий Games/launch lifecycle, приложения через Apps.
- [ ] Профильные тесты, ARM-сборка, визуальная проверка и доступные устройства.
- [ ] PROJECT_STATUS/CHANGELOG, commit/push и проверка удалённой ветки.

Динамический серверный delta-каталог #146, остальные три рецепта, отзывы,
донаты и system-module SPI остаются отдельными незавершёнными требованиями.
Проверенный локальный реестр пакетов не выдаётся за серверную синхронизацию.
