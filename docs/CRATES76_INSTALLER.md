  находятся оба бинарных архива, upstream-исходники, исходники раннера/рецептов и
  SHA256SUMS. Это экспериментальные пакеты, не системная бета TrainerOS.

## Что не объявляется завершённым

- Физический геймпад и Home/минимизация с реальных кнопок, полноценный игровой
  сеанс и совместимость иных устройств требуют отдельной приёмки.
- Сейчас у каждого проекта одна опубликованная версия. Downgrade и защита
  занятого приложения проверены синтетическими архивами, не двумя публичными релизами.
- Сохраняется предыдущая версия при неуспешной замене; автоматического отката
  после неисправности уже запущенного приложения пока нет. Retry скачивает заново.
- Установка не обещает поддержку RA, обложек или всех ROM-функций для native-игр.
- Следующий блок: серверный delta-каталог #146, затем оставшиеся рецепты; отзывы,
  донаты и модули остаются в общем плане.

Локальные логи/снимки: `work/crates76/`. Прежняя витрина CRATES-75 не считается
доказательством установки. При первом выпуске предусмотрена только одна версия
каждого пакета; механизм downgrade проверяется отдельными тестовыми архивами.
