## Результат для игрока

GameHub → RetroAchievements сначала показывает игры с подтверждёнными наборами.
Обложки в объёмных рамках, название, платформа и известный прогресс. Выбор открывает
витрину; B возвращает к той же игре. Касание и джой равноправны. Просмотр другой
игры не меняет Home и не запускает её. Возврат из другой вкладки сохраняет место.

Основной экран показывает связанные с библиотекой подтверждённые RA-наборы.
По уточнению владельца общая история аккаунта вынесена в одну компактную кнопку:
она открывает прокручиваемую всплывашку, а не ещё одну вкладку или витрину.
Без аккаунта — красивое информативное состояние и вход в существующие настройки.

## История аккаунта

Используется официальный [User Completion Progress Web API](https://api-docs.retroachievements.org/v1/get-user-completion-progress.html),
а не локальный набор игр под видом полной истории. Нужен отдельный личный Web API
key из настроек RA; ввод через существующую защищённую клавиатуру в RA account.
Он хранится в закрытом файле текущего профиля; провайдер не возвращает сохранённый
ключ в QML, логи или состояние навигации. Ввод маскируется обычной клавиатурой.
Пароль эмуляторного входа и его Connect token не заменяют Web API key.

Загрузка только по запросу, по 100 записей; Load more получает следующую порцию.
Список содержит название, платформу, известный прогресс Standard/Hardcore и дату
последнего достижения, когда она доступна. Это история прогресса RA, не журнал
каждого запуска/каждого события. Текущий список сохраняется в памяти при сетевой
ошибке; после перезапуска историю нужно загрузить снова. На 10000 записей запросы
останавливаются, счётчик продолжает показывать реальное число загруженных/всего.
Нет предзагрузки скриншотов/обложек всех чужих библиотеке игр или фонового polling.
Смена/выход аккаунта отменяет публикацию старого ответа и очищает его записи.

## Проверки и границы

- ARM `achievements`, `hall`, `achievement_gallery_qml_smoke` проходят; проверены
  новая независимая навигация, возврат к архиву, смена аккаунта, чужие/неизвестные
  данные, API-пагинация и сохранение загруженной истории при ошибке сети.
- QML: выбор → достижения → средняя карточка, фильтр, offline/logout, возврат,
  компактная история, блокировка фоновых действий; виртуальный SDL-контроллер.
  Витрина/карточка также проверены в 720p, 1080p и 4:3. Скриншоты просмотрены.
- Расширенный `experience`: 24 passed, 3 failed. Ожидания Home-фокуса до кнопки
  Lobby, прежнего состава знакомых и GameHub-вкладок при открытом Social расходятся
  с текущим интерфейсом. Контроль с исходным `ShellController.cpp` из `7e3882e`
  воспроизвёл все три сбоя. Это частичный контроль, не сборка чистого старого commit;
  общий набор не объявляется зелёным, нужна отдельная актуализация этих сценариев.
- Общая история проверена на воспроизводимых ответах официального контракта.
  Живая загрузка истории личного аккаунта остаётся непроверенной без его Web API key.
  Тестовые записи не подставляются в обычную установку.
- Физическая оценка владельцем, живые новые достижения во время игры и джингл
  остаются на ранее согласованном этапе приёмки RA-56; эта работа их не закрывает.
