# HUB-50 — Overview и горизонтальная Timeline

**Концепция заменена последующим решением владельца:** Overview теперь про
общий путь игрока по всем играм. Ниже — история реализации прежнего варианта,
а не актуальный целевой экран. См. [HUB-51](HUB51_PLAYER_JOURNEY.md).

## Согласовано 16 октября 2026

Владелец принял композицию Overview: название/платформа сверху, крупный
последний игровой кадр слева, время/число сессий/последний запуск справа,
последние события снизу. Timeline — настоящая горизонтальная лента:
более ранние запуски слева, новые справа; крестовина/стик и свайп.
Стиль — существующие объёмные рамки, пастельные акценты и цвет корпуса.

Уточнение владельца после первых кадров: широкая единая рамка отвергнута.
Снимки показываем компактным наклонённым коллажем перекрывающихся рамок,
в том же стиле, что принятый коллаж Home. Весь Overview должен быть красивым
и изящным, включая пропорции, статистику и интервалы. Повторно используем
HomeScreensCollage: настоящий сохранённый кадр впереди, декоративная рамка
позади; она не выдаётся за второй сохранённый снимок.
Следующее уточнение: в Overview три перекрывающиеся рамки. Пока доступен один
сохранённый снимок, две задние — декоративные места альбома. Home сохраняет
свои две рамки; новые кадры из архива #203 здесь пока не заявляются.

## Точный объём этого прохода

1. Заменить базовую композицию Overview; кадр открывает существующий Screens,
   последние события — Timeline. У новой игры тематическое оформление без
   выдуманных сессий или скриншотов. Универсально, включая игры с адаптером.
2. Показывать общее записанное время и полный счётчик сессий текущего Trainer
   и игры. Существующий кэш содержит только последние 50 сессий; счётчик должен
   учитывать все записи. В ленте явно обозначить ограничение последних 50.
3. Горизонтальная линия с карточками над/под ней, датами, длительностью и
   исходом сессии. По умолчанию виден правый, новый край. Возврат и смена игры
   не должны оставлять чужую историю или неверный индекс.
4. Проверить агрегат при >50 запусках и смене Trainer, собрать native/ARM,
   проверить заполненный/пустой экран и управление, доставить на доступные
   Odin/Flip, посмотреть реальные снимки. Commit/push и публикационные записи.

Полный Screens/index/viewer (#203), точные live RA-снимки (#204), отдельные
RA/Adapter/Lobby и архивная пагинация старше 50 сессий остаются следующими
блоками. #202 не закрывается этим проходом. Обсуждаем экраны по очереди.
Лента соблюдает порядок реальных запусков даже при изменении часов; расстояния
между карточками равномерные, без заявления о масштабе календарных интервалов.

Источники: [#202](https://github.com/EriArk/TrainerOS/issues/202),
[#203](https://github.com/EriArk/TrainerOS/issues/203), актуальная реплика владельца.
