## Точная схема

- B из правой части — влево на активную категорию.
- Слева ↑/↓: поиск, All rooms, категории, свободные места, фильтры.
  Перемещение фокуса само по себе не применяет категорию.
- A на категории применяет её и возвращает к комнатам справа. При отсутствии
  комнат выбирается Create lobby / My lobby.
- Справа ↑/↓ перемещают по рядам, ←/→ — по колонкам. За боковой границей
  страницы перелистываются, если следующая/предыдущая существует.
- ↑ из первого ряда — Create lobby / My lobby; ↓ — обратно к запомненной комнате.
- Выбор комнаты хранится по стабильному ID, в том числе при обновлении каталога.
  Смена локального Trainer-профиля сбрасывает фокус. Touch пользуется теми же действиями.
- Фокус слева виден лёгкой рамкой; подсветка справа при этом отключена.
  Подсказки внизу соответствуют активной стороне. Вход в комнату остаётся на A.
