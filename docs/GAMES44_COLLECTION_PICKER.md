# GAMES-44 — добавление игры в коллекцию

## Согласованный сценарий

Уточнение владельца от 16 октября 2026 заменяет предложение отдельного экрана
редактора: Select на игре → Add to collection → компактная всплывашка с выбором
ручной коллекции или созданием новой с этой игрой. Автоматический редактор #199
(ALL/ANY/EXCLUDE, предпросмотр, исключения, миграция) отложен до специального
раздела настроек. Не расширяем старый автоматический редактор в этом проходе.

## Реализация

- Контекстное действие использует существующий общий GameCollections и профильное
  хранилище; новой базы коллекций нет.
- Список ручных коллекций показывает название, число игр и галочку принадлежности.
  Выбор добавляет игру и закрывает окно. Повторное добавление идемпотентно;
  удаление остаётся отдельным действием старого редактора состава коллекции.
- Create collection открывает ввод имени и компактное подтверждение Create & add
  game. До подтверждения коллекция не сохраняется. Cancel/Back возвращает список
  без нового объекта. Пустое имя не сохраняется.
- Создание и отмена закреплены снизу, длинный список прокручивается.
  В старом меню Select включена прокрутка указателем: действие ниже первого
  экрана теперь доступно и касанием. Название
  выбранной игры видно под заголовком; обе формы доступны касаниями и контроллером.
- Сохраняются атомарная запись, изоляция Trainer, существующие автоматические
  определения и защищённый отказ при нечитаемом хранилище. Поздний ввод после
  закрытия/смены профиля не меняет данные.
- Старые независимые маршруты управления коллекциями не заменяются большим новым
  редактором. Этот инкремент меняет именно добавление из контекста игры.

## Проверка и поставка

Native и ARM сборки прошли. 23 SeriesTests прошли, включая путь Select на
зарегистрированной игре без запуска или смены Home, создание/отмену,
пустое имя, повторное добавление без дублей, несколько коллекций для одной игры,
повторное чтение, смену профиля и сохранность старых/нечитаемых данных.
UI smoke прошёл: пустая коллекция, создание и добавление, существующая отметка,
13 коллекций с длинными названиями, прокрутка до последней, фокус контроллера,
нажатия Create/Cancel указателем. Итоговые файлы:
`build/games44-series.txt`, `build/games44-smoke/collections-verification.txt`,
`build/games44-smoke/collection-picker-{empty,create,added,many,scrolled}.png`.
Промежуточный сценарий ошибочно выбирал справочную запись без регистрации;
его заменили UI-проверкой самого picker и отдельным тестом Select на
зарегистрированной игре. Найденные перехват фокуса скрытым редактором и выход
кнопок за рамку исправлены до итоговой поставки.

Одинаковая финальная ARM-сборка установлена на Odin и Flip:
`b9931f0ad13cf27cf70cd7b3c02ee38c69d7e4a21f2e3d0d9a3f93aa944c2585`.
Проверены хеши запущенных процессов, исходники ARM, целостность БД и неизменность
игровых сессий; ошибок QML нет, системная громкость осталась нулевой.

На реальных библиотеках Odin (Pokémon Platinum) и Flip (Pokémon Rumble U)
просмотрены меню Select, новая всплывашка и форма создания. Проверены удалённые
нажатия/перетаскивание указателем для прокрутки меню и открытия Add to collection,
переход к клавиатуре, отмена имени/создания и возврат в библиотеку.
Реальные пользовательские коллекции в этих проверках не создавались; сохранение
и повторное чтение покрыты автоматическими тестами, а не выданы за ручную
проверку сохранения на устройстве. Локальные кадры/квитанции:
`work/evidence/games44-final-{odin,flip}/` — `touch-scroll.png`, `picker.png`,
`create-cancel.png`, `returned.png`, `verification.json` (не публичные assets).

Визуальная приёмка владельцем и физический ввод на портативках остаются отдельно.
Следующий шаг — просмотр этой всплывашки владельцем и обсуждение следующего
экрана по принятому поэкранному порядку. Автоматический редактор/настройки
не начинаем; весь #199 этим инкрементом не закрывается.
