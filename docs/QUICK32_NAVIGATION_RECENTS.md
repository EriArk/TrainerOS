# QUICK-32 — подсказки подразделов и четыре Recent games

16 октября 2026. Коррекция владельца поверх QUICK-31 и #227, без изменения
общей структуры экранов, назначений основных кнопок и жизненного цикла игр.

## Принято

- Общая подсказка L1/R1 удалена со всех экранов. Сами кнопки продолжают
  переключать основные разделы.
- Для Games, GameHub, Social, Apps отдельные «‹ L2» и «R2 ›» стоят слева
  и справа от переключаемых подразделов. Без цветных подложек; стрелки и
  надписи в общей палитре. Подсказки также действуют по касанию через общий
  semantic dispatch, с прежними ограничениями модальных окон и клавиатуры.
- Если подразделов много, подсказки обрамляют название выбранного и счётчик.
  Если переключать нечего, лишних стрелок нет.
- Окончательное уточнение Home: только скрыть подсказки. Переключение между
  друзьями, уведомлениями и игрой через L2/R2 остаётся. Промежуточное сообщение
  об удалении самого переключения отменено следующим уточнением владельца.
- Recent games показывает четыре карточки на ширине экрана вместо трёх.
  Карточки ниже, с прежними лентами, превью и историей; длинные подписи
  сокращаются многоточием. Высота панели 162 вместо 188, карточки 124 вместо
  150, промежутки 10 вместо 14. Общий скос и анимация QUICK-31 сохранены.

## Проверки и доставка

Windows native build и Home UI smoke прошли, `qmlWarnings=0`. Проверены
размещение четырёх карточек, отдельные подсказки вокруг подразделов, общий
переход Apps → Crates → Apps через сигналы новых подсказок. Существующий
сценарий Home подтверждает переключение друзья → уведомления → игра.
Проверки X/Y, выбора, меню и вертикальной анимации остаются зелёными.

ARM Release установлен на Odin и Flip. SHA-256 работающих бинарников:
`2f74bbe822d3a20243dbbd4db4e37f8950075b20cfe3e17960512bad31ae5888`.
Исходники ARM-сборки совпадают с манифестом. На обоих устройствах QML-ошибок
нет, SQLite цела, количество и последняя игровая сессия совпадают до/после.
Odin оставлен с громкостью 0. Игры и приложения не запускались.

Просмотрены реальные снимки Home, Recent games, Apps, Social, GameHub и
корня Games на обеих портативках. Четыре карточки помещаются полностью,
надписи не пересекаются; на Home подсказок нет. В корне Games нет ряда
подразделов, поэтому стрелки там также скрыты. На Odin удалённым указателем
проверено касание R2 → Crates и L2 → Apps. На обоих устройствах проверены
X, выбор приложения, Select/возврат, переход к Y и выбор Recent games.
