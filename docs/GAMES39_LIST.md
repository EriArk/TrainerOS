# Games — List с перелистыванием страниц

16 октября 2026. Wheel принят владельцем после доставки `3355597`.
Перед работой перечитаны #198 и GAMES38. Следующий согласованный экран — List.

- Та же левая доля 38% и тот же экземпляр GameInformation справа: компоновка,
  описание, рамка, метаданные, название и действия не копируются.
- Слева обычные красивые строки с тонкими разделителями, небольшими сведениями
  о платформе/недоступном файле. Выделение — тонкая светящаяся рамка с мягким
  ореолом без кнопочной заливки и тени (последнее уточнение владельца).
- Уточнение владельца: прокрутка целыми страницами, по семь строк.
  Высота строки подстраивается при необходимости, строки не обрезаются. вверх/вниз выбирают строку и перелистывают на границе;
  влево/вправо крестовиной или левым стиком переключают целую страницу;
  свайп/колесо/стрелки переводят страницу. Номер страницы показывает положение.
- Владелец заменил верхний выбор Wheel/List нажатием R3. Подсказка R3 View
  внизу также нажимается пальцем; выбор в Select остаётся. Верхних переключателей
  нет. Y/X остаются прежними. Это уточнение заменяет
  прежнее ограничение #198 на назначение кнопки для переключения вида.
- Вид хранится по семантическому ID в навигации текущего Trainer отдельно для
  каждой платформы/коллекции; старое состояние по умолчанию Wheel.
- Смена вида не меняет выбранный Adventure ID, Home, фильтр, историю или ROM.
  Пустой список, отсутствующие файлы и медиа используют общий путь.

Проверки: сохранение вида/ID через смену контекста, refresh/restart, недопустимые
значения и модальные блокировки; страницы, финальная неполная страница и длинные
названия; общий правый renderer; native/ARM и UI в нескольких размерах.
Затем доставка на обе доступные портативки и реальные кадры списка, переключения
и страниц без запуска игр. Shelves/Grid пока не входят; #198 остаётся открыт.

Последняя коррекция плотности: семь строк вместо пяти; платформа справа
в той же строке, без второго этажа подписи. Рамка и постраничное поведение прежние.


## Реализация и проверка

`LibraryWheel` сохраняет общий split и один экземпляр GameInformation; новый
`LibraryGameList` заменяет только левое содержимое. Страница содержит максимум
семь делегатов. Размер страницы задаёт общая модель MultiversePresentation;
касание и крестовина используют одинаковый размер. Вид записывается как
`wheel`/`list`, неизвестные значения не принимаются, старые записи дают Wheel.
Новая семантика ChangeView связывается с SDL RIGHTSTICK; направление левого стика
использует существующий общий механизм направлений. R3 игнорируется вне браузера
и при блокирующих панелях. При короткой последней странице выбирается доступная
строка, перелистывание за края не зацикливается.

Native/ARM собраны. `trainer_series_tests`: 17 passed; в том числе библиотека
с 300 дополнительными играми, страницы/края, scoped view, refresh/restart,
неизменность launch ID/Home и модальные блокировки. UI smoke PASSED на 960×540,
1920×1080 и 1280×800: R3 виртуального SDL-геймпада, касание подсказки, семь строк,
свайп ровно на страницу без запуска, последняя неполная страница и общий renderer.
Проверочный Qt Test подключён только при BUILD_TESTING, не в ARM-поставке.
Локальные результаты: `build/games39-series.txt`, `build/games39-smoke/`.

Промежуточные версии с верхним выбором вида, кнопочным выделением и пятью строками
заменены текущей компоновкой по последним уточнениям владельца. Wheel ранее принят
владельцем ([3355597](https://github.com/EriArk/TrainerOS/commit/3355597)); List
ожидает отдельного визуального просмотра. Shelves/Grid и #198 целиком не закрыты.
