# Games: единый корневой экран — 16 октября 2026

## Согласованная компоновка

Home временно принят владельцем. Следующий экран — корень Games (#197).
Шесть круглых иллюстрированных коллекций в одном видимом ряду, подписи снизу.
Ниже — одна горизонтальная лента вертикальных обложек платформ строго 3:4.
Количество обложек рассчитывается по доступной высоте/ширине с небольшими
равными промежутками; пять — ориентир, не обязательное количество.
Стрелки по краям каждой ленты видны только при наличии скрытого содержимого
в данном направлении; доступны касанием. Нижний отступ обложек компактный,
без оставшейся от прежней компоновки пустой полосы. Тонкий разделитель.
Search на корне убран. Сохраняем иллюстрации, объёмные рамки и общий масштаб.

Это последнее уточнение владельца заменяет промежуточные 5 прямоугольных
коллекций / 4 платформы, платформы 4 × 2 и предложение 8 круглых коллекций.

## Границы и действия

1. Верхняя лента: серии, автоматические и пользовательские коллекции, затем
   настоящая карточка создания. All games/Favorites остаются службами, не плитками.
2. Нижняя лента: платформы реальной библиотеки; вход сразу в существующее колесо
   игр этой платформы. Back возвращает в тот же блок к той же карточке.
3. Выбор коллекции ведёт прямо к её играм. Просмотр не изменяет Home, историю
   запусков, ROM, сохранения или адаптер. Внутри браузера L2/R2 переключают
   области только своей категории; на корне не переключают карточки.
4. На корне нет Search: последнее уточнение владельца заменяет этот пункт #197.
   Существующий поиск внутри браузера остаётся. X/Y сохраняют
   глобальные панели. Создание/редактирование использует существующий редактор;
   новый редактор сложных правил #199 остаётся следующим отдельным экраном.
5. Фокус и прокрутки сохраняются независимо; идентичность карточки — её ID.
   Старые сохранённые маршруты поддерживаются, отдельный выбор платформ
   через All games больше не нужен.
