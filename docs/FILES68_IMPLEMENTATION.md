# Files — план и проверка интеграции

17 октября 2026. Владелец временно приостановил Social и выбрал Files, затем Browser.
Основание: [issue #229](https://github.com/EriArk/TrainerOS/issues/229).

## Согласованная компоновка

- Слева постоянная компактная колонка мест и накопителей. Сетевые места — только
  действительно поддержанные установленным файловым backend, без фиктивных подключений.
- Сверху тонкая полупрозрачная панель breadcrumbs; каждый родитель открывается нажатием.
- Кнопки управления **снизу**, в ушке из корпуса в стиле X, между ушком Y и правой
  стенкой. Уточнение владельца 18 октября: контур ушка подогнан по ширине кнопок,
  их координаты и расстояния сохранены. С обеих сторон короткие плавные скаты
  в нижний корпус, свободное пространство после Y сохранено. Это заменяет прежнее
  растягивание ушка до правой стенки и верхнюю панель управления из первоначального #229.
- Обычные файлы/папки, настоящие иконки, миниатюры, сетка/список; без отдельных
  декоративных карточек. Палитра, скаты, отступы и фокус общие с TrainerOS.
- Select скрывает/показывает нижнее управление; breadcrumbs сохраняются сверху.
  Крестовина — фокус, стики — указатель/прокрутка, короткое A открывает,
  удержание A/пальца — контекст. X/Y и L2/R2 сохраняют общие действия.

## Основа

Выбрана **libfm-qt 2.4.0 (PCManFM-Qt), LGPL-2.1-or-later**. Переиспользуются
модели и реальные операции; TrainerOS предоставляет QML-представление и подключение
к общей клавиатуре/задачам. Не копируем PCManFM как отдельное desktop-окно.

Сравнение 17 октября:

- libfm-qt доступен в Fedora ARM64; библиотека пакета около 2.8 MiB, это **не** размер
  всех зависимостей и **не** измеренный расход памяти. Qt Widgets/GIO входят в зависимости.
- MauiKit FileBrowsing предоставляет QML, но требует MauiKit и KDE-компоненты; пакеты
  mauikit не найдены запросом доступных репозиториев сборочного контейнера. Сборка и
  поддержка дополнительного UI-стека усложняют этот вариант.
- KIO уже установлен на устройствах; прямое использование KIO потребовало бы собственного
  связывания файловой модели и представления. Сохраняем как альтернативу при проблемах libfm.

Проверка в ARM64 контейнере Odin: Qt 6.11.2, libfm-qt 2.4.0; чтение каталога,
копирование с совпадением содержимого и конфликт с Skip прошли. Для корректного
typed signal connection требуется `-fPIC` (без него получали `signal not found`).
Это **не** проверка установленного Files/Gamescope и не приёмка операций на личных файлах.

Источники: [libfm-qt](https://github.com/lxqt/libfm-qt),
[MauiKit FileBrowsing](https://invent.kde.org/maui/mauikit-filebrowsing).

## Реализация и проверка 17 октября

`FilesService` выполняет задания libfm-qt в рабочих потоках. `FilesController` хранит
навигацию, выделение, clipboard и диалоги; операции переживают переключение экранов.
Задачи показываются в общих Downloads как файловые операции. Имена с конфликтами
не перезаписываются молча; доступны Skip, Keep both, Replace и Cancel. Неподдерживаемая
корзина не превращается в окончательное удаление. При завершении службы ожидающие
конфликты отменяются без сигналов уже разбираемому интерфейсу.

Papirus используется ограниченным набором SVG для папок, мест и типов файлов;
источники, ревизия, авторы и GPL сохранены в `assets/icons/files/`. Управляющие
значки соответствуют существующему семейству Phosphor/TrainerOS. Миниатюры локальных
изображений сохраняют пропорции. Отдельный процесс desktop-файлового менеджера не нужен.

- ARM64 Release собран. Тесты файловой службы: **13 passed, 0 failed**, включая
  copy/rename, четыре ответа на конфликт, отмену при закрытии, отсутствующий источник,
  отмену удаления и защиту имени от выхода в родительскую папку.
- Windows development: сборка прошла; 5 тестов прошли, 8 Linux-only случаев пропущены.
  Там каталог доступен только для чтения. UI-сценарий 1600×900 / 960×540 завершился
  кодом 0, `qmlWarnings=0`; проверены сетка, список, меню, подтверждение, Quick Apps и возврат.
  Найденное при первом прогоне падение на завершении устранено перед финальной проверкой.
- **Одинаковая сборка установлена и запущена на Odin и Flip.** SHA-256:
  `d73f53b09f8e262749ed06b358365830577d10a1d797d17fc8265b3d98a3603b`.
  Совпадение запущенных бинарников подтверждено; журналы после UI-проверок без ошибок QML.
  База прошла `quick_check`, количество/последний запуск игровых сессий не изменились.
- Реальный Gamescope: просмотрены Files на обоих устройствах, сетка/список на Odin,
  домашняя папка и Documents, каталог SD на Odin. На Odin через установленный UI выполнены
  long-press → Copy → переход в папку → Paste, затем конфликт → Keep both.
  Содержимое оригинала и обеих копий совпало; отдельные тестовые файлы затем удалены.
  Громкость Odin осталась 0%.
- Runtime-библиотеки для этой доставки размещены рядом с приложением, не заменяют
  системные Qt/GIO и не экспортируются в окружение эмуляторов. Воспроизводимая упаковка:
  `packaging/linux/bundle-files-runtime.sh`; сохраняются версии пакетов, лицензии и SHA-256.

## Открытая приёмка и границы

ещё не проверена. Существующие FilePicker/ROM import сохраняются; новой несовместимой
версии пикера нет. Добавление готового результата Downloads прямо в Files остаётся
отдельной связкой. Обновление изменившейся извне папки доступно через Refresh.
