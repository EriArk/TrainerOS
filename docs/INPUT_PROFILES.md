# Настройки и игровые профили ввода

## Реализация — 25 октября 2026

Settings открываются из Start отдельным экраном. Шесть разделов используют
стабильные идентификаторы страниц; старые числовые входы сохранены для существующих
потребителей. Внутри раздела L2/R2 переключают страницы. В редакторе игры эти
кнопки переключают Setup / Buttons / Radial menus, а при выборе назначения —
категории клавиш. Touch обращается к тем же действиям.

По текущему решению владельца Settings используют простую светлую поверхность,
типографику, тонкие разделители и небольшие акценты фокуса. Объёмные caps,
градиентные кнопки и заливки каждого ряда не являются образцом для этого экрана.
Вложенные звук, связь, сеть и часы получают тот же плоский вариант компонентов;
прочие потребители компонентов сохраняют прежний режим.

### Устройство

`ControllerInput` распознаёт семейство через SDL type/name. Для проверенного
виртуального маршрута InputPlumber дополнительно читает физическое имя Retroid/Odin.
Ручной выбор: Auto, Nintendo, Xbox, PlayStation, Steam, Generic. Семейство меняет
подписи общих `Hint`, диагностики и схемы контроллера; Confirm/Back выбираются
семантически, с отдельным ручным override. Неизвестное устройство получает
позиционные обозначения и доступный ручной выбор.

Профиль хранится в QSettings по GUID, для распознанного виртуального handheld —
по физическому имени. Есть зона покоя, инверсия левого стика, сброс и вход в
существующую диагностику. Изменение требует отпустить органы управления перед
следующим действием. Linux-помощники читают атомарную проекцию
`$XDG_RUNTIME_DIR/traineros-shell-input.json`: физическое имя, Confirm/Back и
инверсия навигации. Это не второй постоянный профиль.

### Игра

`GameInputProfiles` владеет черновиком и атомарным JSON под
`<state>/input/<sha256(owner)>/<sha256(game)>.json`. Выбираются PC и native Crates
игры из существующей библиотеки. Изменение применяется со следующего запуска;
отмена черновика не меняет сохранённый профиль, смена Trainer очищает редактор.

Доступны исходный gamepad либо клавиатура/мышь; WASD/стрелки на левом стике,
курсор/прокрутка на правом, зона покоя и скорость; назначения физических кнопок,
слой при удержании плечевой кнопки и до четырёх колец. Редактор создаёт восемь
секторов. Палитра включает мышь, буквы, цифры, служебные и F-клавиши, несколько
готовых сочетаний. Home зарезервирован. Произвольный скрипт не является назначением.

В кольце удержание назначенной кнопки открывает оверлей, левый стик выбирает
сектор, отпускание выполняет действие; центр отменяет. Tap сектора передаёт
одно действие через тот же помощник, повторное открытие требует отпустить кнопку.

### Исполнение и восстановление

В существующий `AdventureOverlayService` передаётся снимок профиля конкретной
игры. Linux `adventure-overlay.py` сохраняет прежнюю lease/Home/exit цепочку.
В режиме keyboard/mouse InputPlumber перехватывает gamepad, а независимый watchdog
выдаёт XTest-события только окну действующей игры с проверенным process identity.
Отображение кольца использует существующий нефокусируемый `InvitationOverlayService`.

Клавиши учитываются множеством: отпускание одной из двух назначенных кнопок не
снимает общий выход. Потеря foreground, Home, disconnect, EOF, отсутствие кадров
или ошибка освобождают выход; повторный ввод проходит нейтральный барьер.
При потере помощника сервис отключает mapping до следующего запуска и возвращает
обычный маршрут управления. Игровые сохранения этим механизмом не изменяются.

**Предел текущего исполнения:** существующий Linux X11/Xwayland маршрут с
проверенными физическими RawPad Retroid/Odin. Это не Windows input backend,
не native Wayland injection и не подтверждение совместимости произвольного
внешнего контроллера, Steam Input или каждой PC-игры. Обнаружение внешнего
контроллера в оболочке шире текущего runtime mapping.

## Проверка и оставшаяся приёмка

Локальные проверки: C++ сохранение/изоляция/валидация профилей и смена glyphs с
нейтральным барьером; Python mapping, модификатор, кольцо, touch, disconnect,
потеря focus и watchdog EOF/timeout; QML-сценарий Settings с изображениями
960×540 и 1280×720. Результаты текущего запуска записываются в CHANGELOG.

На портативки этот инкремент не установлен. Нужны настоящие физические кнопки,
hotplug, Linux XTest/InputPlumber game loop, Home/return/exit, touch кольца,
сон/recovery и проверка оформления владельцем. Полная калибровка осей/триггеров,
произвольные сочетания, tap/hold, дополнительные экранные панели, все типы
устройств и хостов остаются открытыми в #77/#250. Полные Light/Dark темы и
остальные требования #234 также не закрываются этой поставкой. Installer/OTA,
SDK и multiplayer принадлежат своим текущим работам.
