# Home card landscapes

Five original landscape backdrops generated with the built-in image_gen tool
on 2026-10-16. The full prompts and palette constraints are in [prompts.json](prompts.json).
No input/reference screenshots, characters or franchise assets were supplied.
Each source PNG is used at its original 1536 × 1024 resolution, with rounded
clipping in HomeCardBackdrop.qml; it never becomes the entire screen background.

The tonal teal, burgundy, sage, slate blue and copper scenes follow the chassis
palettes in Theme.qml. They replace the earlier flat vector placeholder for
both generic and adapter game cards, without changing adapter ownership.
All five outputs were visually inspected. The existing project asset/licence
review in #116 remains separate; this record does not clear unrelated artwork.
