Selected at the owner's request on 2026-10-18 for the Crates catalogue and project
popup. These are real third-party projects, not TrainerOS releases. No executable,
source package, soundtrack, installation command or compatibility certification
is included. The images below are upstream promotional screenshots, not captures
of applications running on TrainerOS. All files are unmodified originals.

and SHA-256 hashes are in [sources.json](sources.json). GPL artwork is supplied
here in its original form, with notices and source provenance. Product names
identify their respective projects; no endorsement is implied.

The ordinary catalogue uses `sample: true` and **empty Crates release lists**.
This does not deny that upstream projects publish releases. Packaging and actual
handheld/controller checks must happen before a Crates download can be offered.
Workshop stays reserved for TrainerOS projects; these examples appear in What's
New and manually selected thematic crates. The selection can be replaced later.
