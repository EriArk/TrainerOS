# Crates showcase illustrations

Original six-scene atlas generated with the built-in OpenAI image tool on
2026-10-18 for the owner-approved Crates concept. Source is `illustrations-wide.png`,
1254 × 1254; six panoramic 1254 × 209 strips, in showcase order.
The showcase atlas contains no third-party game artwork, logos or screenshots.
Separate temporary project examples and their upstream notices are documented in
[examples/README.md](examples/README.md). `gamepad.svg` is original TrainerOS
vector artwork, covered by the repository's GPL-3.0-or-later source licence.

Prompt: six independent, warm painterly illustrations for small crate insets:
sunrise explorers, maker workshop, forest mountains, arcade platforms,
miniature strategy city, tools and modules. Dusty teal, sage, gold, coral and
lavender; large readable shapes; no text, frames or recognizable franchises.
The final prompt requested six full-width horizontal panoramic strips with all
important subjects fitting inside each strip; this replaces the first square-cell
draft whose subjects were cropped too heavily in the actual UI. Native resolution
returned by the built-in tool is recorded above, rather than the requested size.

Only illustrations are raster assets. The live labels, lids, catches, materials,
focus and opening animation are QML. This atlas is not a screenshot of products
available to install. Keep the source intact; QML selects each cell.
