# Гольфовая коллекция — примерка

[Обзор на персонажах](review.html) · [Blender-исходник](golf-wardrobe.blend) ·
[Состав и контрольные суммы](collection.json)

Два комплекта для текущего тела Trainer. Каждая вещь — самостоятельный GLB,
включая пары носков и обуви. Внутри сборок вещи также остаются отдельными мешами.
«Мужской» и «женский» обозначают сочетания; пол персонажа не ограничивает вещи.

| Вещь | Мужской комплект | Женский комплект |
| --- | --- | --- |
| Верх | [Поло с рукавами](polo-short-sleeve.glb) | [Поло без рукавов](polo-sleeveless.glb) |
| Низ | [Гольфовые шорты](golf-shorts.glb) | [Плиссированная юбка](pleated-skirt.glb) |
| Носки | [Короткая пара](ankle-socks.glb) | [Пара повыше](crew-socks.glb) |
| Обувь | [Зелёная отделка](golf-shoes-classic.glb) | [Персиковая отделка](golf-shoes-sport.glb) |
| Головной убор | [Кепка](golf-cap.glb) | [Козырёк](golf-visor.glb) |

[Мужская сборка](mens-outfit.glb), [женская сборка](womens-outfit.glb),
[все десять вещей](golf-wardrobe.glb) содержат только одежду и общий скелет.
Тело, волосы и глаза в них не продублированы. Юбка открыта снизу: новых шорт под
ней нет, используется нижний слой исходного тела.

## Редактирование и совместимость

- Метрическая система, Y вверх, +Z вперёд, общий origin и bind pose
  `trainer-humanoid-54-v1`; 54 кости, восемь клипов. Масштабировать каждую вещь
  отдельно перед надеванием не нужно.
- Ткань и отделка имеют самостоятельные материалы `ivory`, `forest`, `peach`,
  `sole`, `dark`, `metal`. Это редактируемые материалы GLB/Blender, пока не новые
  поля опубликованного API внешности.
- Поло, шорты и носки подогнаны по поверхности утверждённого тела. Веса и
  корректирующие формы вырезанной ткани перенесены по исходным треугольникам,
  без перескока на соседнюю поверхность в подмышке. Стыки UV сварены в геометрии
  одежды. Само тело не изменялось.
- Воротники, планки, пуговицы, карманы, складки, подошвы, шнурки, кепка и козырёк
  построены отдельно. Кепка примеряется с `crop`, козырёк с `bob`; посадка на
  остальных причёсках требует отдельной проверки.
- Это skinned mesh, **симуляции ткани нет**. Юбка следует тазу и бёдрам; глубокие
  позы и специальные движения гольфа требуют оценки в целевой игре.
- В Blender-файле группы `mens - separate garments` и `womens - separate garments`.
  По умолчанию виден мужской набор; для женского скрыть первый и включить второй.
  Скелет общий, меши и материалы редактируются отдельно.

## Проверки и статус

[Структурная проверка](validation.json) проверяет десять отдельных экспортов,
точное совпадение bind pose, веса, корректирующие формы и восемь анимаций.
[Godot import](godot-import.json) проверяет загрузку всех десяти GLB и наличие
скелета, корректирующих форм и основных анимаций в Godot 4.7.2.
Кадры в обзоре — настоящие Blender-рендеры этих моделей на текущем персонаже.

Это авторская примерка для визуального обсуждения. В системный гардероб,
resolver и установленные игры коллекция пока не подключена. Текущий runtime
pack revision 6 и утверждённые исходники сохранены. Следующий шаг после выбора
внешнего вида — подключение самостоятельных предметов через общий гардероб SDK,
проверка сочетаний и гольфовых анимаций.

## Воспроизведение

Из корня репозитория (Python 3.12, numpy, scipy, Pillow):

```text
python tools/avatar/build_golf_clothes.py --output assets/avatar/collections/golf-v1
python tools/avatar/check_golf_clothes.py assets/avatar/collections/golf-v1
```

`tools/avatar/render_golf_review.py` запускается в Blender и принимает `--male`
и `--female` с путями к разрешённым через общий SDK аватарам, а также `--out`.
Он сохраняет редактируемый Blender-файл и снимает ракурсы/позы. `--duo-only`
снимает общую карточку. `tools/avatar/check_golf_godot.gd` — headless-проверка
импорта, аргумент `--collection=` указывает на эту папку.

Новые внешние модели, бренды или изображения для коллекции не скачивались.
Часть ткани построена по утверждённому телу; прежние
[границы происхождения и лицензирования](../../README.md) сохраняются.
