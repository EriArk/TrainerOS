# Стартовые и гоночные костюмы — примерка

[Четыре образа и ракурсы](review.html) ·
[Blender-исходник](starter-racing-wardrobe.blend) · [Состав и хеши](collection.json)

Четыре образа на принятом персонаже TrainerOS. Второй гоночный вариант имеет
молочно-розовое оформление и более приталенный крой. Пол персонажа не ограничивает выбор одежды.

| Комплект | Новые самостоятельные предметы |
| --- | --- |
| Стартовый сарафан | [Цельный сарафан со складками](sundress.glb); существующая пара сандалий |
| Стартовый повседневный | [Футболка](everyday-tee.glb), [джинсовые бриджи](denim-breeches.glb), [кеды](canvas-shoes.glb) |
| Гоночный | [Комбинезон](racing-suit.glb), [шлем](racing-helmet.glb), [ботинки](racing-boots.glb), [перчатки](racing-gloves.glb) |
| Гоночный Rose | [Комбинезон](rose-racing-suit.glb), [шлем](rose-racing-helmet.glb), [ботинки](rose-racing-boots.glb), [перчатки](rose-racing-gloves.glb) |

Сарафан — одна вещь: лиф непрерывно переходит в юбку через общие вершины
и треугольники. Складки раскрываются ниже талии; снизу остаётся открытый подол.
Дополнительные шорты под него не создавались. Лямки и отделка принадлежат тому же
предмету. Комбинезоны экспортируются целиком; шлемы, перчатки и обувь отдельно.

## Совместимость

- Общий скелет `trainer-humanoid-54-v1`: 54 кости, исходные bind matrices,
  восемь клипов, 46 каналов корректирующих форм. Метры, Y вверх, +Z вперёд.
- Исходные тело, лицо, волосы и действующий пакет revision 7 сохранены.
- Материалы редактируются отдельно. Визор полупрозрачный. Под закрытым шлемом
  волосы скрываются в примерке; снятие возвращает прежнюю причёску.
- Отдельная поверхность примерки не переносит край базовых шорт на длинную
  одежду. Сглаживание ткани согласованно переносит веса и корректирующие формы.
- Это skinned mesh без симуляции ткани. Показанные позы не сертифицируют все
  движения или коллизии в игре.

## Проверки и статус

[Структурная проверка](validation.json) проверяет вещи, скелет, веса, анимационные
каналы, хеш исходного тела и контур/зазор ткани над старым краем шорт в шести сечениях.
Отдельные геометрические проверки контролируют плавность бокового силуэта
сарафана, зазор между заправленными штанинами и голенищами обоих комплектов,
а также плавный задний контур от пятки до голенища без ступеньки над узкой щиколоткой.
[Рендеры](render-evidence.json) привязаны хешами к коллекции: четыре ракурса,
поднятые руки, шаг, приседание, поворот. Для гонок есть вид без шлема.

Два стартовых комплекта предназначены для бесплатного получения после создания
персонажа. Это доступность предметов, не выдача дополнительных платных слотов
сохранённых образов. Автовыдача пока не реализована.

**Доделано:** четыре комплекта / двенадцать новых предметов, Blender-исходник,
GLB, проверка экспорта и обзор.
**Недоделано:** принятие внешнего вида, подключение цельных вещей/перчаток и
скрытия волос к гардеробу, стартовая выдача, доставка и игровая проверка.

## Воспроизведение

Из корня репозитория, Python 3.12 с numpy/scipy и Blender 5.2:

```text
python tools/avatar/build_starter_racing.py
python tools/avatar/check_starter_racing.py assets/avatar/collections/starter-racing-v1
blender --background --python tools/avatar/render_starter_racing.py -- --male resolved-crop.glb --female resolved-bob.glb
blender --background --python tools/avatar/render_starter_racing.py -- --male resolved-crop.glb --female resolved-bob.glb --lineup-only
python tools/avatar/publish_starter_racing.py
```

Входные персонажи разрешаются существующим `avatar-resolve` из общего пакета.
Рендер записывает хеши обоих входов. Для отдельной правки доступны
`build_starter_racing.py --only-set <id>` и `render_starter_racing.py --only <id>`.

Новых сторонних моделей, брендов или изображений не использовано.
[Границы происхождения исходного персонажа](../../README.md) сохраняются.
