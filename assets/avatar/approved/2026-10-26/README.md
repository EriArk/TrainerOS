# Утверждённая внешность — 26 октября 2026

Владелец принял новую спортивную майку с тонкими лямками и уменьшение головы
вместе с причёсками на 8%. По отдельному поручению эти результаты сохранены
в репозитории вместе с редактируемым исходником и проверками.

| Файл | Назначение |
| --- | --- |
| `avatar-authoring.blend` | Редактируемый персонаж, отдельная майка с четырёхугольной сеткой, четыре отдельные причёски, скелет и упакованные текстуры |
| `sports-tank.glb` | Только новая майка и её привязка к общему скелету; тело в файл не включено |
| `avatar-all-hair-options.glb` | Полный кандидат для дальнейшей интеграции; просмотрщик должен включить ровно одну из четырёх `hair-*` моделей |
| `head-proportions.png` | Слева прежняя голова, справа уменьшенная; одинаковая камера |
| `tank-movement.png` | Поднятые руки, поворот, присед спереди/сзади, шаг и поднятые руки сзади |
| `evidence.json` | SHA-256 файлов, параметры и фактические границы проверки |

Новая майка создана отдельно под тело персонажа; геометрия прежней скачанной
майки не использована. В ней 3872 вершины / 7440 треугольников при экспорте,
четыре ожидаемых отверстия и нормализованные веса. Область под проймами получает
веса от поверхности торса; соседняя рука исключена из доноров. Физической
симуляции ткани нет. Отдельный объект можно скрыть, перекрасить или заменить.

Голова и все варианты волос масштабированы на 0,92 вокруг исходного сустава
головы; на шее оставлен плавный переход. Лицо сохраняет собственные пропорции.
Проверены точное сохранение скелета, анимационных буферов, UV, весов, майки,
обуви, тела ниже шеи и его корректирующих дельт. В этой версии также сохранена
локальная правка отмеченного владельцем залома у внутреннего шва шорт:
топология, UV и веса прежние, поверхность сглажена по противоположной стороне.

Экспорт GLB повторно загружен в Blender. Майка проверена на 72 отсчётах восьми
клипов и на показанных ракурсах; уменьшенная голова просмотрена в нейтральной
позе и `Wave`. Это авторская/локальная проверка, не запуск в игре или на устройстве.
Существующие [границы происхождения и лицензий](../../README.md) тела, волос
и обуви сохраняются; одобрение внешности не меняет права на сторонние компоненты.
