# Исправленная базовая модель Trainer

Это отдельная основа персонажа, на которую надеваются одежда, обувь и волосы.
27 октября 2026 она извлечена без изменения геометрии из ранее одобренной
[сборки](../2026-10-26/anime-hair/README.md), по требованию владельца хранить
само тело отдельно. Ранее отдельный актуальный файл тела не был сохранён.

- [trainer-body.glb](trainer-body.glb) — один меш тела с головой, полный скелет,
  текстуры и восемь анимаций; без майки, обуви и волос.
- [trainer-body.blend](trainer-body.blend) — редактируемый Blender-исходник,
  полученный повторным импортом этого GLB, с упакованными текстурами.
- [trainer-body.png](trainer-body.png) — проверочный рендер отдельного тела.
- [validation.json](validation.json) — точное сравнение с одобренной сборкой.
- [evidence.json](evidence.json) — контрольные суммы и проверка импорта.

Сохранены уменьшение головы до 92%, исправление дефекта у внутреннего шва
шорт (92 вершины), полная сетка под одеждой, UV, веса, 54 кости и 46 корректирующих
форм. Базовые шорты являются частью исходного тела. Никакой новой лепки,
масштабирования или исправления поверхности при извлечении не выполнялось.

Это исправленный оригинал с прежним лицом/глазами. Подготовленная область лица
для новых сменных глаз остаётся отдельной производной в
[chibi-eyes](../2026-10-26/chibi-eyes/README.md); не накладывайте её глаза
поверх старого рисунка и рельефа век этого оригинала.

Извлечение воспроизводится стандартным Python из корня репозитория:

```text
python tools/avatar/export-standalone-body.py assets/avatar/approved/2026-10-26/anime-hair/avatar-all-hair-options.glb assets/avatar/approved/base-body/trainer-body.glb
```

Проверены точное сохранение буферов тела и анимаций, полный набор треугольников,
текстуры, повторный импорт и рендер в Blender. SDK/runtime и устройства не
обновлены. [Происхождение и условия использования](../../README.md) прежние.
