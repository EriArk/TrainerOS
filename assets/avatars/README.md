# TrainerOS avatar pack — 18 October 2026

Six original AI-generated portraits requested by the owner: Explorer, Pilot,
Mage, Robot, Fox and Diver. Generated with the built-in image generation tool;
independent square illustrations, resized to 512 × 512 for distribution.
No existing franchise character or third-party reference image was requested.

The profile picture chooser offers these alongside the user's Pictures files.
Selection uses the existing explicit profile-update flow. Merely opening the
picker never uploads anything or replaces an existing profile photograph.
Initial-letter placeholders retain their identity and now have varied colours.

These PNGs are artwork, separate from the GPL code grant; the artwork boundaries
in ../../LICENSING.md and the public artwork review under #116 still apply.
The generated source images remain in the owner's private generation archive.
