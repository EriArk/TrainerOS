# Security reporting

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/EriArk/TrainerOS/security/advisories/new).
Private reporting is enabled for this repository. Do not publish credentials,
exploitable details or personal saves in a public issue.

Include the affected commit/build, platform, minimal reproduction, impact and
redacted logs if useful. Use synthetic data wherever possible. Do not attach
commercial ROMs, firmware, encryption keys or other users' data.

TrainerOS is in active development and has no stable security-support release
matrix yet. Reports should identify the exact version; remediation is handled
against current development unless a maintained release is explicitly announced.
No response-time or bug-bounty commitment is implied.

For ordinary crashes, controller problems and feature requests, use
[repository issues](https://github.com/EriArk/TrainerOS/issues).
